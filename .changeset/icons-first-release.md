"@audio-ui/icons": minor
---

Icons: the first release. 63 glyphs for audio interfaces (a knob, a fader, a rack unit, a piano, the shape of a filter, a wave that dies away), one thin stroke on a 24 grid, in four weights (`regular`, `bold`, `duotone`, `fill`). `@audio-ui/icons` is data for any framework: the glyphs, the `catalog` with each icon's category and the words to find it by, `toSvg` for the text of an SVG file and `draw` for the same drawing as plain nodes. `@audio-ui/icons/react` is the React components, named for what they draw (`KnobIcon`, `LowpassIcon`).
