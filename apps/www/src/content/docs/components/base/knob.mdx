Rotary knob for continuous parameters (level, cutoff, pan, etc.). The registry component wraps the `Knob` primitive from `@audio-ui/react` with size variants and theme styles.

## Overview

- **Interaction model:** Circular drag by default (or `dragMode="vertical"` / `"revolution"`), mouse wheel, keyboard, and **double-tap / double-click** to snap back to `defaultValue`.
- **Feedback:** Track rail, highlighted arc between `anchor` and the value, and a needle that rotates with the value. The needle follows the pointer directly, with no easing, so it never lags behind the arc.
- **Accessibility:** The knob holds a native `<input type="range">` that takes focus, carries the accessible name (`aria-label` / `aria-labelledby`), the value text (formatted with `format`, or `getAriaValueText` on the primitive's `Thumb`), and the form value (`name`).

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { Knob } from "@audio-ui/react";

<Knob.Root>
  <Knob.Control>
    <Knob.Track />
    <Knob.Indicator />
    <Knob.Thumb />
    <Knob.Mark value={50} />
  </Knob.Control>
  <Knob.Value />
  <Knob.Label />
</Knob.Root>
```

## Usage

```tsx
import { Knob } from "@/components/audio/knob";
```

**Uncontrolled** - initial value only:

```tsx
<Knob defaultValue={50} max={100} min={0} step={1} />
```

**Controlled** - drive the value from state (typical in audio UIs):

```tsx
const [cutoff, setCutoff] = useState(1000);

<Knob
  max={20_000}
  min={20}
  onValueChange={setCutoff}
  step={1}
  value={cutoff}
/>
```

Pass **`defaultValue`** even when controlled if you use **double-tap reset**; it defines the value the knob jumps back to (still clamped and stepped).

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Circular drag (default)** | The value follows the rotation around the center, from the value at pointer down. The dial's 288° sweep spans `min…max`. |
| **Vertical drag** | `dragMode="vertical"`: drag up to increase, like a fader; 150px of travel spans `min…max`. |
| **Revolution drag** | `dragMode="revolution"`: one full 360° turn spans `min…max`. |
| **Fine drag** | Hold `Shift` while dragging, in any mode, to turn four times slower. Only the stretch moved with `Shift` held is slowed, and small moves add up rather than rounding away. |
| **Double-tap / double-click** | Two quick taps (each moving ≤ ~12px, within ~320ms) reset to `defaultValue`, or to the middle of the dial's travel without one. Reports `eventDetails.reason === "reset"`. |

Values always **clamp** to `min…max` (no wrap). While dragging, the knob follows the pointer even if a controlled `value` updates late.

### Scale

`scale` sets how the value maps onto the dial's travel. `"linear"` (the default) suits levels and times; `"log"` suits frequency, resonance and ratios, which ears hear in proportions: on a 20 Hz–20 kHz cutoff, every decade gets the same share of the dial, and 632 Hz sits at the middle. A log scale needs a positive `min`. For anything else, pass your own `{ toPosition, toValue }`, mapping a value to 0…1 along the travel and back.

```tsx
<Knob aria-label="Cutoff" max={20_000} min={20} scale="log" />
```

Away from linear, the keys and the wheel move a share of the travel (1%, or 10% with `Shift` and the Page keys) rather than a `step`, and always by at least one `step`.

### Keyboard

On the focused knob:

| Key | Action |
| --- | ------ |
| `ArrowUp` / `ArrowRight` | Increase by `step` |
| `ArrowDown` / `ArrowLeft` | Decrease by `step` |
| `PageUp` / `Shift` + `ArrowUp` | Increase by `largeStep` (default `10`) |
| `PageDown` / `Shift` + `ArrowDown` | Decrease by `largeStep` (default `10`) |
| `Home` | `min` |
| `End` | `max` |

### Wheel

Wheel input over the knob steps the value by `step` and reports `eventDetails.reason === "wheel"`.

### Thumb

Rotates with the value (`rotate`, clockwise from 12 o'clock), so a pointer drawn inside it points at the value. ### Mark

A graduation on the dial at `value`, placed on the knob's scale: a layer the size of the knob, rotated to where `value` sits, so a tick drawn at its top lands on the sweep. Its `--knob-mark-angle` CSS variable is that rotation, to turn a label back upright. It carries `data-active` while the value has reached it from the anchor. Decorative: the input announces the value. Renders a `<div>` element.

`@audio-ui/react/knob` exposes `Knob.Root`, `Knob.Control` (pointer, wheel, reset), `Knob.Track` and `Knob.Indicator` (SVG arcs; `strokeWidth` in the 48×48 viewBox), `Knob.Thumb` (rotates with the value and holds the input), `Knob.Value` (formatted `<output>`), `Knob.Mark` (a graduation at a `value`, rotated onto the dial's scale, with `data-active` once reached), and `Knob.Label`. Every part accepts a `render` prop, `className` / `style` as functions of state, and exposes `data-disabled` / `data-dragging`.
