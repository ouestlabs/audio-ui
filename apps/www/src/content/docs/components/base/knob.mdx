Rotary knob for continuous parameters (level, cutoff, pan, etc.). The registry component wraps the `Knob` primitive from `@audio-ui/react` with size variants and theme styles.

## Overview

- **Interaction model:** Circular drag by default (or `dragMode="vertical"` / `"revolution"`), mouse wheel, keyboard, and **double-tap / double-click** to snap back to `defaultValue`.
- **Feedback:** Track rail, highlighted arc between `anchor` and the value, and a needle that rotates with the value. The needle follows the pointer directly, with no easing, so it never lags behind the arc.
- **Accessibility:** The knob holds a native `<input type="range">` that takes focus, carries the accessible name (`aria-label` / `aria-labelledby`), the value text (formatted with `format`, or `getAriaValueText` on the primitive's `Thumb`), and the form value (`name`).

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { Knob } from "@audio-ui/react";

<Knob.Root>
  <Knob.Control>
    <Knob.Track />
    <Knob.Indicator />
    <Knob.Thumb />
    <Knob.Mark value={50} />
  </Knob.Control>
  <Knob.Value />
  <Knob.Label />
</Knob.Root>
```

## Usage

```tsx
import { Knob } from "@/components/audio/knob";
```

**Uncontrolled** - initial value only:

```tsx
<Knob defaultValue={50} max={100} min={0} step={1} />
```

**Controlled** - drive the value from state (typical in audio UIs):

```tsx
const [cutoff, setCutoff] = useState(1000);

<Knob
  max={20_000}
  min={20}
  onValueChange={setCutoff}
  step={1}
  value={cutoff}
/>
```

Pass **`defaultValue`** even when controlled if you use **double-tap reset**; it defines the value the knob jumps back to (still clamped and stepped).

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Circular drag (default)** | The value follows the rotation around the center, from the value at pointer down. The dial's 288° sweep spans `min…max`. |
| **Vertical drag** | `dragMode="vertical"`: drag up to increase, like a fader; 150px of travel spans `min…max`. |
| **Revolution drag** | `dragMode="revolution"`: one full 360° turn spans `min…max`. |
| **Fine drag** | Hold `Shift` while dragging, in any mode, to turn four times slower. Only the stretch moved with `Shift` held is slowed, and small moves add up rather than rounding away. |
| **Double-tap / double-click** | Two quick taps (each moving ≤ ~12px, within ~320ms) reset to `defaultValue`, or to the middle of the dial's travel without one. Reports `eventDetails.reason === "reset"`. |

Values always **clamp** to `min…max` (no wrap). While dragging, the knob follows the pointer even if a controlled `value` updates late.

### Scale

`scale` sets how the value maps onto the dial's travel. `"linear"` (the default) suits levels and times; `"log"` suits frequency, resonance and ratios, which ears hear in proportions: on a 20 Hz–20 kHz cutoff, every decade gets the same share of the dial, and 632 Hz sits at the middle. A log scale needs a positive `min`. For anything else, pass your own `{ toPosition, toValue }`, mapping a value to 0…1 along the travel and back.

```tsx
<Knob aria-label="Cutoff" max={20_000} min={20} scale="log" />
```

Away from linear, the keys and the wheel move a share of the travel (1%, or 10% with `Shift` and the Page keys) rather than a `step`, and always by at least one `step`.

### Keyboard

On the focused knob:

| Key | Action |
| --- | ------ |
| `ArrowUp` / `ArrowRight` | Increase by `step` |
| `ArrowDown` / `ArrowLeft` | Decrease by `step` |
| `PageUp` / `Shift` + `ArrowUp` | Increase by `largeStep` (default `10`) |
| `PageDown` / `Shift` + `ArrowDown` | Decrease by `largeStep` (default `10`) |
| `Home` | `min` |
| `End` | `max` |

### Wheel

Wheel input over the knob steps the value by `step` and reports `eventDetails.reason === "wheel"`.

## API reference

### Root

Groups all parts of the knob and owns its value. Dragging the `Control`, turning the mouse wheel over it, the keyboard on the `Thumb`'s input, or a double tap (reset) all report through `onValueChange` / `onValueCommitted`. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `anchor` | `number` |  | Value the indicator arc grows from (e.g. `0` on a -1…1 pan knob). Defaults to `min`. |
| `defaultValue` | `number` |  | Uncontrolled starting value, and the double-tap reset target. Defaults to the middle of the dial's travel. |
| `disabled` | `boolean` |  |  |
| `dragMode` | `DragMode` | `"circular"` |  |
| `form` | `string` |  | Identifies the form that owns the knob's input, when rendered outside it. |
| `format` | `Intl.NumberFormatOptions` |  | Formats the value for `Knob.Value` and the input's `aria-valuetext`. |
| `largeStep` | `number` | `10` | Step for Page Up/Page Down and Shift + Arrow keys. |
| `locale` | `Intl.LocalesArgument` |  |  |
| `max` | `number` | `100` |  |
| `min` | `number` | `0` |  |
| `name` | `string` |  | Identifies the field when a form is submitted. |
| `onValueChange` | `(value: number, eventDetails: ChangeEventDetails) => void` |  | Fires on every change: drag, keyboard, wheel, reset and input changes. |
| `onValueCommitted` | `( value: number, eventDetails: CommitEventDetails ) => void` |  | Fires when an interaction ends with a new value. |
| `scale` | `Scale` | `"linear"` | How the value maps onto the dial's travel: `linear`, `log` for frequency, Q or ratios (needs a positive `min`), or your own `{ toPosition, toValue }`. Away from linear, the keys and the wheel move a share of the travel (1%, or 10% with Shift and Page keys) rather than a `step`. |
| `step` | `number` | `1` |  |
| `value` | `number` |  |  |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |

### Thumb

Rotates with the value (`rotate`, clockwise from 12 o'clock), so a pointer drawn inside it points at the value. Holds the knob's native `<input type="range">`, which takes focus, carries the accessible name (`aria-label` / `aria-labelledby`) and the form value, and handles the keyboard. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `getAriaValueText` | `(formattedValue: string, value: number) => string` |  | Returns the input's `aria-valuetext`, e.g. `"-6 dB"`. Defaults to the formatted value. |
| `inputRef` | `React.Ref<HTMLInputElement>` |  |  |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging the knob. |

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `\| React.ReactNode \| ((formattedValue: string, value: number) => React.ReactNode)` |  |  |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |

### Mark

A graduation on the dial at `value`, placed on the knob's scale: a layer the size of the knob, rotated to where `value` sits, so a tick drawn at its top lands on the sweep. Its `--knob-mark-angle` CSS variable is that rotation, to turn a label back upright. It carries `data-active` while the value has reached it from the anchor. Decorative: the input announces the value. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` |  | Where the mark sits, on the knob's scale. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging the knob. |
| `data-active` | Whether the value has reached this mark from the anchor. |

### Label

Accessible label, associated with the thumb's input. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging the knob. |

### Registry component

`Knob` accepts **`size`** and **`className`** plus primitive props from `KnobPrimitive.Root.Props`. `aria-label`, `aria-labelledby`, and `aria-describedby` are forwarded to the knob's input.

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | - | Controlled value. |
| `defaultValue` | `number` | middle of the travel | Uncontrolled starting value, and the double-tap reset target. |
| `min` | `number` | `0` | Minimum. |
| `max` | `number` | `100` | Maximum. |
| `step` | `number` | `1` | Quantization step (drag, wheel, keyboard, reset). |
| `largeStep` | `number` | `10` | Step for `PageUp` / `PageDown` and `Shift` + arrows. |
| `anchor` | `number` | `min` | Where the highlighted arc starts, e.g. `0` on a bipolar pan knob. |
| `dragMode` | `"circular" \| "vertical" \| "revolution"` | `"circular"` | How pointer travel turns into value. |
| `scale` | `"linear" \| "log" \| { toPosition, toValue }` | `"linear"` | How the value maps onto the dial's travel. |
| `marks` | `(number \| { value, label? })[]` | - | Graduations drawn around the dial, on its scale. Those the value has reached from `anchor` light up. |
| `valueLabel` | `"auto" \| "always" \| "hidden"` | `"auto"` | When the value shows under the dial: `auto` while hovered, turned or focused from the keyboard. |
| `formatValue` | `(value: number) => string` | `format` | How the value prints in that readout, e.g. `"8.7 kHz"`. |
| `disabled` | `boolean` | `false` | Disables pointer, wheel, and keyboard. |
| `format` | `Intl.NumberFormatOptions` | - | Formats the value text announced to screen readers (and `Knob.Value` on the primitive). |
| `locale` | `Intl.LocalesArgument` | runtime | Locale used by `format`. |
| `name` | `string` | - | Submits the value with a form. |
| `onValueChange` | `(value: number, eventDetails) => void` | - | Every change. `eventDetails.reason` is `"drag"`, `"keyboard"`, `"wheel"`, `"reset"`, or `"input-change"`; call `eventDetails.cancel()` to reject it. |
| `onValueCommitted` | `(value: number, eventDetails) => void` | - | When an interaction ends with a new value (pointer up, key press, wheel tick, reset). |
| `size` | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` | Diameter variant. |
| `className` | `string` | - | On the root wrapper. |



`@audio-ui/react/knob` exposes `Knob.Root`, `Knob.Control` (pointer, wheel, reset), `Knob.Track` and `Knob.Indicator` (SVG arcs; `strokeWidth` in the 48×48 viewBox), `Knob.Thumb` (rotates with the value and holds the input), `Knob.Value` (formatted `<output>`), `Knob.Mark` (a graduation at a `value`, rotated onto the dial's scale, with `data-active` once reached), and `Knob.Label`. Every part accepts a `render` prop, `className` / `style` as functions of state, and exposes `data-disabled` / `data-dragging`.
