## Anatomy

Import the registry component for the ready-made look, or compose the primitive's parts yourself.

```tsx
import { Sequencer } from "@audio-ui/react";

<Sequencer.Root>
  <Sequencer.Rows>
    {(row) => (
      <Sequencer.Row index={row}>
        <Sequencer.Cells>
          {(step) => <Sequencer.Cell step={step} />}
        </Sequencer.Cells>
      </Sequencer.Row>
    )}
  </Sequencer.Rows>
</Sequencer.Root>;
```

## Usage

```tsx
import { Sequencer } from "@/components/audio/elements/sequencer";

<Sequencer
  aria-label="Drum pattern"
  onValueChange={setPattern}
  rowLabels={["Kick", "Snare", "Hihat"]}
  source={step}
  value={pattern}
/>;
```

`value` is a row per sound, each a list of steps: `boolean[][]`. `source` is the step being played, a live `{ getSnapshot, subscribe }` such as one made with `createSource`: a clock ticking every step never re-renders React.

## Interaction

| Gesture | What it does |
| --- | --- |
| Press a step | Flips it. |
| Drag on | Paints the new state across every step the pointer crosses. |
| Arrow keys, `Home`, `End` | Move between steps; with `Ctrl` or `Cmd`, `Home` and `End` go to the corners. |
| `Space`, `Enter` | Flip the focused step. |

The steps are one tab stop, and each is a toggle button (`aria-pressed`) named after its row and step.

## API reference

### Root

Groups the parts and owns the pattern. Renders a `<div>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `boolean[][]` | | The pattern: a row per sound, each a list of steps. |
| `defaultValue` | `boolean[][]` | | The starting pattern, when uncontrolled. |
| `onValueChange` | `(value, eventDetails) => void` | | Fires while steps flip. `eventDetails.reason` is `"press"`, `"paint"` or `"keyboard"`; `eventDetails.cancel()` keeps the pattern as it was. |
| `onValueCommitted` | `(value, eventDetails) => void` | | Fires when a gesture that changed the pattern ends, and after each key press. |
| `source` | `{ getSnapshot, subscribe }` | | The step being played. Its cells get `data-current`. |
| `disabled` | `boolean` | `false` | Stops the pointer and the keyboard. |
| `className`, `style`, `render` | | | Each can be a function of the state. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-painting` | Present while a pointer paints. |

### Rows

Calls `children(row)` once per row. Renders nothing of its own.

### Row

One sound's row of steps. Renders a `<div>` with `role="group"`; name it with `aria-label`.

| Prop | Type | Description |
| --- | --- | --- |
| `index` | `number` | Which row this is, from the top. |

### Cells

Calls `children(step)` once per step of the row it is in. Renders nothing of its own.

### Cell

One step: a toggle button. Renders a `<button>`.

| Prop | Type | Description |
| --- | --- | --- |
| `step` | `number` | Which step this is, from the left. |

| Data attribute | Description |
| --- | --- |
| `data-on` | Present when the step is on (also `aria-pressed`). |
| `data-current` | Present on the step being played. |
| `data-disabled` | Present when disabled. |
| `data-painting` | Present while a pointer paints. |

### Registry component

`Sequencer` takes the `Root` props, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rowLabels` | `string[]` | | Names written beside each row, and its accessible name. |
| `beatEvery` | `number` | `4` | Highlights every nth step. |
