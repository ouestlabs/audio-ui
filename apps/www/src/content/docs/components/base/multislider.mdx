Multislider for editing an array of values in one gesture (for example step velocities, harmonic partials, or band gains). The registry component wraps `Multislider` primitives from `@audio-ui/react` and renders one fill bar per array entry.

## Overview

- **Interaction model:** Absolute-position painting — pressing a slider jumps it to the pointer, dragging across sliders paints every crossed column (fast swipes interpolate so no column is skipped).
- **Value model:** `value` / `defaultValue` is a `number[]`; the array length is the slider count. All sliders share `min`, `max`, and `step`.
- **Orientation:** Vertical bars side by side (default) or horizontal bars stacked top to bottom.
- **Accessibility:** One roving tab stop; each slider is a `role="slider"` with the fader key map, and arrow keys move focus between sliders.

## Usage

```tsx
import { Multislider } from "@/components/audio/multislider";
```

**Uncontrolled** - initial values only:

```tsx
<Multislider defaultValue={[0.2, 0.5, 0.8, 0.4]} />
```

**Controlled** - drive values from state:

```tsx
const [levels, setLevels] = useState([0.3, 0.6, 0.85, 0.5]);

<Multislider
  onValueChange={setLevels}
  onValueCommit={(values) => console.log("Committed:", values)}
  value={levels}
/>
```

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Press on a slider** | The touched slider jumps to the pointed value. |
| **Drag across sliders** | Every crossed slider is painted; values between two pointer samples are interpolated. |
| **Clamping** | Values always clamp to `min` / `max` and quantize to `step`. |
| **Commit event** | `onValueCommit` fires when the drag ends. |

### Keyboard

One tab stop for the whole component; focus then roves between sliders:

| Key | Action (vertical) |
| --- | ------ |
| `ArrowUp` / `ArrowDown` | Increase / decrease the focused slider by `step` |
| `ArrowLeft` / `ArrowRight` | Move focus to the previous / next slider |
| `PageUp` / `PageDown` | Increase / decrease by `step × 10` |
| `Home` / `End` | Set the focused slider to `min` / `max` |

With `orientation="horizontal"` the axes swap: `ArrowLeft` / `ArrowRight` adjust the value and `ArrowUp` / `ArrowDown` move focus.

### Wheel

Wheel over a slider nudges that slider by `step` per tick.

## API reference

`Multislider` accepts style props (`size`, `thumbs`, `className`) plus primitive props from `MultisliderPrimitive.RootProps`.

### Value and state

| Prop            | Type                                    | Default       | Description                                                      |
| --------------- | --------------------------------------- | ------------- | ------------------------------------------------------------------ |
| `value`         | `number[]`                              | -             | Controlled values; the array length is the slider count.        |
| `defaultValue`  | `number[]`                              | `[0.5, 0.5, 0.5, 0.5]` | Uncontrolled default values.                            |
| `min`           | `number`                                | `0`           | Minimum value shared by all sliders.                             |
| `max`           | `number`                                | `1`           | Maximum value shared by all sliders.                             |
| `step`          | `number`                                | `0.01`        | Step increment shared by all sliders.                            |
| `orientation`   | `"vertical" \| "horizontal"`           | `"vertical"`  | Bar direction and paint axis.                                    |
| `disabled`      | `boolean`                               | `false`       | Whether the multislider is disabled.                             |
| `onValueChange` | `(values: number[]) => void`            | -             | Callback when values change during interaction.                  |
| `onValueCommit` | `(values: number[]) => void`            | -             | Callback when values are committed (on release).                 |
| `aria-label`    | `string`                                | `"Multislider"` | Accessible name for the slider group.                          |
| `aria-labelledby` | `string`                              | -             | ID of a labeling element.                                        |

### Layout and display

| Prop            | Type                                    | Default       | Description                                                      |
| --------------- | --------------------------------------- | ------------- | ------------------------------------------------------------------ |
| `size`          | `"sm" \| "default" \| "lg" \| "xl"`    | `"default"`   | Size variant (affects height).                                   |
| `thumbs`        | `"visible" \| "hidden"`                | `"hidden"`    | Shows a mark at each slider's value edge.                        |
| `className`     | `string`                                | -             | Additional CSS classes.                                         |

Additional valid HTML attributes passed to `Multislider.Root` are forwarded.
