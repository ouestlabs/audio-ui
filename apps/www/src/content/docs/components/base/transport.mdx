## Usage

```tsx
import { Transport } from "@/components/audio/elements/transport";

<Transport
  bpm={bpm}
  looping={looping}
  onBpmChange={setBpm}
  onLoopingChange={setLooping}
  onPlay={() => engine.play()}
  onRecordingChange={setRecording}
  onReturn={() => engine.seek(0)}
  onStop={() => engine.stop()}
  playing={playing}
  recording={recording}
  source={position} // seconds, a live value
/>;
```

Play, record and loop are toggle buttons (`aria-pressed`), so they show when they are on; return to start and stop act once. The position reads `bar.beat.sixteenth`, counted from the tempo and the time signature (`tempo`, 4/4 by default).

## API reference

| Prop | Type | Description |
| --- | --- | --- |
| `source` | `{ getSnapshot, subscribe }` | The playback position in seconds, a live value. |
| `bpm`, `onBpmChange` | `number`, `(bpm) => void` | The tempo. |
| `tempo` | `{ beatsPerBar, beatUnit }` | The time signature the position is counted in. Defaults to 4/4. |
| `playing`, `onPlay` | `boolean`, `() => void` | Play is pressed while it plays. |
| `onStop` | `() => void` | Stop was pressed. |
| `onReturn` | `() => void` | Return to start was pressed. |
| `recording`, `onRecordingChange` | `boolean`, `(recording) => void` | Armed to record. |
| `looping`, `onLoopingChange` | `boolean`, `(looping) => void` | Whether the loop is on. |
