## Usage

```tsx
import { Transport } from "@/components/audio/elements/transport";

<Transport
  bpm={bpm}
  looping={looping}
  onBpmChange={setBpm}
  onLoopingChange={setLooping}
  onPlay={() => engine.play()}
  onRecordingChange={setRecording}
  onReturn={() => engine.seek(0)}
  onStop={() => engine.stop()}
  playing={playing}
  recording={recording}
  source={position} // seconds, a live value
/>;
```

Play, record and loop are toggle buttons (`aria-pressed`), so they show when they are on; return to start and stop act once. The position reads `bar.beat.sixteenth`, counted from the tempo and the time signature (`tempo`, 4/4 by default).

<TypeRow name={"recording, onRecordingChange"} type={"boolean, (recording) => void"}>Armed to record.</TypeRow>
