## Usage

```tsx
import {
  Plot,
  PlotArea,
  PlotCurve,
  PlotGraph,
  PlotGrid,
  PlotHandle,
} from "@/components/audio/elements/plot";
import { eqResponse } from "@/lib/filter-response";

<Plot minX={20} maxX={20000} minY={-18} maxY={18} scaleX="log">
  <PlotGrid x={{ count: 6 }} y={{ ticks: [-12, 0, 12] }} />
  <PlotGraph>
    <PlotArea fillTo={0} fn={response} />
    <PlotCurve fn={response} />
  </PlotGraph>
  <PlotHandle
    aria-label="Band 1"
    onValueChange={({ x, y }) => setBand({ frequency: x, gainDb: y })}
    value={{ x: band.frequency, y: band.gainDb }}
  />
</Plot>;
```

`fn` is `y = fn(x)` in the axes' units. The `filter-response` lib gives you the functions for the usual curves: `eqResponse`, `biquadResponse` and `compressorOutput`, and for keeping a band's handle on the curve, `bandHandleDb` (where it sits) and `bandGainForHandle` (the gain that puts it where the pointer is).

## Handles

A handle holds a native `<input type="range">` per axis, so it works from the keyboard: the arrow keys move it by a hundredth of the axis, a tenth with <kbd>Shift</kbd>, and <kbd>Home</kbd> / <kbd>End</kbd> go to the ends. Dragging moves it from where it is rather than jumping to the pointer, and four times finer with <kbd>Shift</kbd>. `axis="x"` or `axis="y"` holds it to one axis.

## Live signals

`PlotTrace` draws a list of y values from a `source` straight in the DOM, with no React render per frame: the spectrum of the sound behind an equalizer, on a scale of its own (`min`, `max`). `PlotDot` is a point that follows a live `{ x, y }`, such as the input level riding a compressor's curve. The `use-spectrum` hook turns an `AnalyserNode` into the source a trace wants, resampled onto a logarithmic frequency axis, and the default example plays pink noise through the equalizer so you hear what you draw.

```tsx
const spectrum = useSpectrum(analyser, { minHz: 20, maxHz: 20000 });

<PlotGraph>
  <PlotTraceArea fillTo={-100} min={-100} max={-10} source={spectrum} />
  <PlotCurve fn={response} />
</PlotGraph>;
```

## API reference

### Plot

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `minX`, `maxX` | `number` | `0`, `1` | Range of the x axis. |
| `minY`, `maxY` | `number` | `0`, `1` | Range of the y axis. |
| `scaleX`, `scaleY` | `"linear" \| "log" \| { toPosition, toValue }` | `"linear"` | How values spread along each axis. |
| `disabled` | `boolean` | `false` | Stops every handle. |

`useValueAtPointer()` returns a function from a pointer position (`clientX`, `clientY`) to a value `{ x, y }` in the axes' units, for adding a point where someone double-clicks or reading out what is under the cursor. Call it from inside a plot.

### PlotCurve, PlotArea

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fn` | `(x: number) => number` | — | The curve: y at each x. |
| `fillTo` | `number` | — | Closes the curve down to this y, for an area. |
| `samples` | `number` | `256` | How many points it is drawn through. |

### PlotTrace, PlotTraceArea

| Prop | Type | Description |
| --- | --- | --- |
| `source` | `{ getSnapshot, subscribe }` | The live y values, spread evenly across the x axis. The snapshot may be one array updated in place. |
| `min`, `max` | `number` | The scale the values are on. Defaults to the plot's y axis. |
| `fillTo` | `number` | Closes the line down to this y, for an area. |

### PlotDot

| Prop | Type | Description |
| --- | --- | --- |
| `source` | `{ getSnapshot, subscribe }` | A live `{ x, y }`, followed without re-rendering. |
| `value` | `{ x: number; y: number }` | A still point. |

### PlotCursor

Crosshair lines that follow the mouse over the plot, with a readout in the corner of what is under it. It is for mouse and pen, not touch, and does its work in the DOM as the pointer moves, so it costs no React render.

| Prop | Type | Description |
| --- | --- | --- |
| `format` | `(value: { x, y }) => string` | Turns the value under the pointer, in the axes' units, into the text shown, such as `1.2 kHz · +3.0 dB`. |

On the primitive, `Plot.Cursor` sets `--plot-cursor-x` and `--plot-cursor-y` (the pointer's place across and down the plot) and `data-active` while the pointer is over it, and `Plot.CursorReadout` writes the text; compose your own lines from the two variables.

### PlotGrid

Grid lines and their labels, worked out from the axes: round values spread along each axis you give, by powers of ten on a logarithmic one, so a plot reads without a line and a label placed by hand for each value.

| Prop | Type | Description |
| --- | --- | --- |
| `x`, `y` | `{ ticks?, count?, format?, labels? }` | What to draw along each axis; leave one out for none. `ticks` sets the values, otherwise about `count` (5) round ones are chosen. `format` writes a label (default "1k", "0.5"), and `labels: false` draws lines alone. |

The line at zero carries `data-zero`, and the parts `data-part="line"` and `"label"` with `data-axis`, for your own styling.

### PlotLine, PlotMark, PlotBand

| Prop | Type | Description |
| --- | --- | --- |
| `axis` | `"x" \| "y"` | `PlotLine`: the line is vertical at an x value, or horizontal at a y value. `PlotBand`: the axis `from` and `to` are on. |
| `value` | `number` | `PlotLine` and `PlotMark`: where on the axis. `PlotMark` is a label ("1k", "+12") at that value. |
| `from`, `to` | `number` | `PlotBand` only. |

### PlotHandle

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` / `defaultValue` | `{ x: number; y: number }` | the middle | The handle's position, in the axes' units. |
| `axis` | `"both" \| "x" \| "y"` | `"both"` | The axes it moves along. |
| `onValueChange` | `(value, eventDetails) => void` | — | While it moves: `reason` is `"drag"`, `"keyboard"` or `"input-change"`. `eventDetails.cancel()` keeps it where it was. |
| `onValueCommitted` | `(value, eventDetails) => void` | — | When a gesture that moved it ends. |
| `getAriaLabel` | `(axis) => string` | — | Names each axis. Defaults to `aria-label`, followed by X / Y. |
| `getAriaValueText` | `(value, axis) => string` | — | Announces each axis, such as "1.2 kHz". |
| `disabled` | `boolean` | `false` | |
