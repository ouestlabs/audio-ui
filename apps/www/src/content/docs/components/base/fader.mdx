Linear fader for continuous parameters (volume, gain, send level, etc.). The registry component wraps the `Fader` primitive from `@audio-ui/react` with size variants and thumb mark styling.

## Overview

- **Interaction model:** Pointer drag on track or thumb, mouse wheel adjustment, keyboard nudging, and commit callbacks on release.
- **Layout:** Vertical (default) or horizontal orientation, with `sm`, `default`, and `lg` size presets.
- **Feedback:** Filled range + thumb with optional internal marks (`thumbMarks`).
- **Accessibility:** The thumb contains a native `<input type="range">` that carries the accessible name (`aria-label` / `aria-labelledby`), the value text (formatted with `format`), and the form value (`name`).

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { Fader } from "@audio-ui/react";

<Fader.Root>
  <Fader.Label />
  <Fader.Control>
    <Fader.Track>
      <Fader.Indicator />
    </Fader.Track>
    <Fader.Mark value={50} />
    <Fader.Thumb />
  </Fader.Control>
  <Fader.Value />
</Fader.Root>
```

## Usage

```tsx
import { Fader } from "@/components/audio/fader";
```

**Uncontrolled** - initial value only:

```tsx
<Fader defaultValue={0} max={6} min={-60} step={1} />
```

**Controlled** - drive value from state:

```tsx
const [gain, setGain] = useState(0);

<Fader
  max={6}
  min={-60}
  onValueChange={setGain}
  onValueCommitted={(value, details) => console.log("Committed:", value, details.reason)}
  step={1}
  value={gain}
/>
```

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Track click / drag** | Clicking or dragging on the track updates the value from pointer position. |
| **Thumb drag** | Dragging the thumb adjusts continuously, clamped to `min...max`. |
| **Commit event** | `onValueCommitted` fires when an interaction ends with a new value. |
| **Lagging value** | While dragging, the thumb follows the pointer even if a controlled `value` updates late; it returns to `value` on release. Reject a value with `eventDetails.cancel()`. |

### Keyboard

Focused thumb supports:

| Key | Action |
| --- | ------ |
| `ArrowUp` / `ArrowRight` | Increase by `step` |
| `ArrowDown` / `ArrowLeft` | Decrease by `step` |
| `PageUp` / `Shift` + `ArrowUp` | Increase by `largeStep` (default `10`) |
| `PageDown` / `Shift` + `ArrowDown` | Decrease by `largeStep` (default `10`) |
| `Home` | Set to `min` |
| `End` | Set to `max` |

### Wheel

Wheel input over the fader nudges the value by `step` and reports `eventDetails.reason === "wheel"`.

## API reference

### Root

Groups all parts of the fader, with audio defaults (vertical, -60…+6) and mouse-wheel stepping. While a pointer drags it, the thumb follows the pointer even if a controlled `value` lags behind (a seek bar driven by playback time, automation) — reject a value with `eventDetails.cancel()` instead. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `anchor` | `number` |  | Value the `Indicator` fills from, such as `0` on a -1…1 pan. Defaults to `min`. |
| `defaultValue` | `number` |  | Uncontrolled starting value; defaults to the midpoint of `min…max`. |
| `max` | `number` | `6` |  |
| `min` | `number` | `-60` |  |
| `onValueChange` | `(value: number, eventDetails: ChangeEventDetails) => void` |  | Fires on drag, track press, keyboard, wheel and form input changes. |
| `onValueCommitted` | `( value: number, eventDetails: CommitEventDetails ) => void` |  | Fires when an interaction ends with a new value. |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |  |
| `value` | `number` |  |  |

| Data attribute | Description |
| --- | --- |
| `data-active` | Whether the value has reached this mark from the anchor. |
| `data-disabled` | Present when disabled. |

### Control

The interactive area: pointer presses and drags, plus mouse-wheel stepping. Sets `touch-action: none` so touch drags don't scroll the page. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-active` | Whether the value has reached this mark from the anchor. |
| `data-disabled` | Present when disabled. |

### Indicator

The filled part of the track: from `min` up to the value, or between the Root's `anchor` and the value, on whichever side of it the value is. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-active` | Whether the value has reached this mark from the anchor. |
| `data-disabled` | Present when disabled. |

### Mark

A graduation along the track at `value`: placed from the start of the travel in the fader's direction, where the thumb's center would be at that value. It carries `data-active` while the value has reached it from the anchor, and `data-orientation`. Decorative: the thumb's input announces the value. Render your own tick and label inside it. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` |  | Where the mark sits, between `min` and `max`. |

| Data attribute | Description |
| --- | --- |
| `data-active` | Whether the value has reached this mark from the anchor. |
| `data-disabled` | Present when disabled. |

### Registry component

`Fader` accepts style props (`size`, `thumbMarks`, `className`) plus primitive props from `FaderPrimitive.Root.Props` (`name`, `form`, `format`, `locale`, `largeStep`, `render`, …). The primitive's `Fader.Mark` places a graduation at a `value` along the track, with `data-active` once the value has reached it, to build your own ruler. `aria-label`, `aria-labelledby`, and `aria-describedby` are forwarded to the thumb's input.

#### Value and state

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | - | Controlled value. |
| `defaultValue` | `number` | midpoint | Uncontrolled initial value. Midpoint is `(min + max) / 2`. |
| `min` | `number` | `-60` | Minimum value. |
| `max` | `number` | `6` | Maximum value. |
| `step` | `number` | `1` | Quantization step for drag, wheel, and keyboard. |
| `marks` | `(number \| { value, label? })[]` | - | Graduations drawn beside the track: a ruler for the value. Those the value has reached from `anchor` light up. |
| `valueLabel` | `"auto" \| "always" \| "hidden"` | `"auto"` | When the value shows beside the thumb: `auto` while hovered, dragged or focused from the keyboard. |
| `formatValue` | `(value: number) => string` | `format` | How the value prints in that readout, e.g. `"-6.0 dB"`. |
| `editableValue` | `boolean` | `false` | Lets you type the value in the readout: a double click, or Enter while it has focus. Enter commits it, Escape drops it (`reason: "input-change"`). |
| `anchor` | `number` | `min` | Value the fill grows from, such as `0` on a -1…1 pan: the fill runs from the anchor to the value, on whichever side it is. |
| `disabled` | `boolean` | `false` | Disables interaction. |
| `onValueChange` | `(value: number, eventDetails) => void` | - | Live updates while adjusting. `eventDetails.reason` is `"drag"`, `"track-press"`, `"keyboard"`, `"wheel"`, `"input-change"`, or `"none"`; call `eventDetails.cancel()` to reject the change. |
| `onValueCommitted` | `(value: number, eventDetails) => void` | - | Fires when an interaction ends with a new value. |
| `aria-label` | `string` | - | Accessible name for the slider. |
| `aria-labelledby` | `string` | - | ID of a labeling element. |

#### Layout and visuals

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | Direction of travel. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Track and thumb size preset. |
| `thumbMarks` | `number \| false` | `3` | Number of marks in the thumb or `false` to hide them. |
| `className` | `string` | - | Root wrapper class name. |

Additional valid HTML attributes passed to `Fader.Root` are forwarded.
