Two detuned oscillators, a distortion mixed in with the clean sound and a low-pass filter. Press the pad: pitch goes across, the resonance up. It is a device like the [compressor](/docs/components/compressor): a state, a panel that draws it, an engine that plays it and tools an agent calls, each its own file.

## Usage

```tsx
import { WaveShaperPanel } from "@/components/audio-ui/devices/wave-shaper/panel";
import { waveShaperDevice } from "@/components/audio-ui/devices/wave-shaper/device";

const [state, setState] = useState(() => waveShaperDevice.defaults());

<WaveShaperPanel onValueChange={setState} value={state} />;
```

The state is a plain object keyed by parameter id, so a host stores it, saves it with its project and sends it where it likes. `waveShaperPitch(position)` and `waveShaperResonance(position)` turn a pad position from 0 to 1 into a note.

## The engine

```ts
import { createWaveShaperEngine } from "@/components/audio-ui/devices/wave-shaper/engine";

const engine = createWaveShaperEngine(ctx, state);
engine.output.connect(ctx.destination);
engine.noteOn(note);  // starts a note, or glides the one being held
engine.noteOff();     // lets it go
engine.update(nextState);
engine.dispose();
```

One voice at a time, as the Pocket Synth. The distortion curve is a table of 44,100 points, rebuilt only when the drive changes.

## The tools

```ts
import { deviceTools } from "@audio-ui/core/device";
import { waveShaperDevice } from "@/components/audio-ui/devices/wave-shaper/device";

const [set, reset, play] = deviceTools(waveShaperDevice);
```

`set` and `reset` change the state, with the ranges the device enforces: a value out of range is brought in and reported, a wrong one is refused by name, and a call never throws.

`play` plays a note: its call gives the parts of the note (a pitch, and a resonance) and how long it lasts, and returns the note and the duration for the host to give to the engine.

```ts
import { playNote } from "@audio-ui/core/device";

const result = play.run(state, input);
if (result.note) playNote(engine, result.note, result.duration ?? 0.5);
```

## Accessibility

Every control is a native input: the knobs are sliders named after their parameter, with the value and unit as the text value, the switch is a toggle button, and everything takes the keyboard.
