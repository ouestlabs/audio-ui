Keeps the sound under a ceiling. The panel draws the transfer curve against the straight line of a clean sound: drag the handle up and down for the ceiling and across for the input gain. It is a device like the [compressor](/docs/components/compressor): a state, a panel that draws it, an engine that plays it and tools an agent calls, each its own file.

## Usage

```tsx
import { LimiterPanel } from "@/components/audio-ui/devices/limiter/panel";
import { limiterDevice } from "@/components/audio-ui/devices/limiter/device";

const [state, setState] = useState(() => limiterDevice.defaults());

<LimiterPanel onValueChange={setState} value={state} />;
```

The state is a plain object keyed by parameter id, so a host stores it, saves it with its project and sends it where it likes. `limiterCurve(state)` is the curve the panel draws.

## The engine

```ts
import { createLimiterEngine } from "@/components/audio-ui/devices/limiter/engine";

const engine = createLimiterEngine(ctx, state);
source.connect(engine.input);
engine.output.connect(ctx.destination);
engine.update(nextState); // parameters ramp: no click
engine.dispose();
```

It is the browser's compressor node at a ratio of 20 with no knee. The node adds a make-up gain of its own that cannot be turned off, so the engine takes it back out and a signal under the ceiling is only as loud as the gain makes it. `engine.reduction` is the gain being taken off, in dB, to read per frame. It is not a look-ahead true-peak limiter: the node's attack is as short as the browser allows.

## The tools

```ts
import { deviceTools } from "@audio-ui/core/device";
import { limiterDevice } from "@/components/audio-ui/devices/limiter/device";

const [set, reset] = deviceTools(limiterDevice);
```

`set` and `reset` change the state, with the ranges the device enforces: a value out of range is brought in and reported, a wrong one is refused by name, and a call never throws.

## Accessibility

Every control is a native input: the knobs are sliders named after their parameter, with the value and unit as the text value, the switches are toggle buttons, and everything takes the keyboard.
