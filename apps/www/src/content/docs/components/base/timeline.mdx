The ground an arrangement, a clip editor or a piano roll is drawn on. The registry component wraps the `Timeline` primitive from `@audio-ui/react`, which knows nothing about tempo: its units are whatever you count in (seconds, beats, pulses, steps), and musical time comes from the `musical-time` lib.

## Overview

- **Units and zoom:** `duration` is the timeline's length in your units, and `zoom` is how many pixels one unit takes. Leave `zoom` unset and the timeline fits the width it is given; zoom it, and every lane is as long as the timeline and the viewport scrolls.
- **Zooming:** Cmd/Ctrl + scroll (or pinch on a trackpad) zooms around the pointer. Whatever changes the zoom, the point it was anchored on stays where it was, or the middle of the view when nothing named one.
- **Grid:** with a `snapStep`, the ruler lands on the grid. Hold Cmd/Ctrl to place the playhead off it, and Shift to scrub four times finer.
- **Playback:** pass a live `source` and every playhead follows it straight in the DOM, with no React render per frame.
- **Ranges:** a `TimelineRange` is a stretch of the timeline (a loop, a selection, a clip): drag it to move it, drag a handle to resize it, or with `drawable` drag across empty lane to draw a new one. It snaps like everything else.
- **Navigator:** `TimelineNavigator` shows the whole timeline as one bar with the visible stretch inside it. Drag the window to scroll, an edge to zoom, double-click to show everything. Pair it with `scrollbar="hidden"` on the viewport and it takes the scrollbar's place.
- **Accessibility:** the ruler, each range, each range handle and the navigator's window and edges hold a native `<input type="range">`, so everything the pointer does works from the keyboard. The ruler's input spans the timeline. It takes focus, carries `aria-label`, announces the position (or whatever `getAriaValueText` returns, such as "Bar 3, beat 2"), and moves by `step` with the arrow keys, `largeStep` with <kbd>Page Up</kbd> / <kbd>Page Down</kbd> and Shift, and to the ends with <kbd>Home</kbd> / <kbd>End</kbd>.

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { Timeline } from "@audio-ui/react";

<Timeline.Root>
  <Timeline.Viewport>
    <Timeline.Ruler>
      <Timeline.Mark value={0} />
      <Timeline.Playhead />
    </Timeline.Ruler>
    <Timeline.Lane>
      <Timeline.Range>
        <Timeline.RangeHandle edge="start" />
        <Timeline.RangeHandle edge="end" />
      </Timeline.Range>
      <Timeline.Playhead />
    </Timeline.Lane>
  </Timeline.Viewport>
  <Timeline.Navigator>
    <Timeline.NavigatorWindow />
    <Timeline.NavigatorHandle edge="start" />
    <Timeline.NavigatorHandle edge="end" />
  </Timeline.Navigator>
</Timeline.Root>
```

## Usage

```tsx
import {
  Timeline,
  TimelineLane,
  TimelineMark,
  TimelinePlayhead,
  TimelineRuler,
  TimelineViewport,
} from "@/components/audio/elements/timeline";
import {
  DEFAULT_TEMPO,
  describeBarsBeats,
  gridInterval,
} from "@/lib/musical-time";
```

```tsx
const snapStep = gridInterval("adaptive", zoom, DEFAULT_TEMPO);

<Timeline
  duration={32}
  onPositionChange={(seconds) => transport.seek(seconds)}
  onZoomChange={setZoom}
  snapStep={snapStep}
  source={transport.position}
  zoom={zoom}
>
  <TimelineViewport>
    <TimelineRuler
      aria-label="Playhead"
      getAriaValueText={(seconds) => describeBarsBeats(seconds, DEFAULT_TEMPO)}
    >
      <TimelineMark value={0}>1</TimelineMark>
      <TimelineMark value={2}>2</TimelineMark>
      <TimelinePlayhead />
    </TimelineRuler>
    <TimelineLane gridStep={snapStep}>
      <TimelinePlayhead />
    </TimelineLane>
  </TimelineViewport>
</Timeline>
```

## Ranges

```tsx
const [loop, setLoop] = useState<readonly [number, number]>([8, 16]);

<TimelineLane>
  <TimelineRange aria-label="Loop" drawable onValueChange={setLoop} value={loop}>
    <TimelineRangeHandle aria-label="Loop start" edge="start" />
    <TimelineRangeHandle aria-label="Loop end" edge="end" />
  </TimelineRange>
</TimelineLane>
```

The range's own input moves it with the arrow keys, by the timeline's `step`; each handle's input moves its edge, which stops `minLength` short of the other one (the grid step by default). `onValueChange` receives `[start, end]` and `eventDetails` with the `edge` that moved (`"start"`, `"end"` or `"both"`) and the `reason` (`"drag"`, `"draw"`, `"keyboard"` or `"input-change"`). Leave the handles out for a range that only moves, or pass `movable={false}` for one that only resizes.

## Navigator

```tsx
<Timeline zoom={zoom} onZoomChange={setZoom} duration={32}>
  <TimelineViewport scrollbar="hidden">…</TimelineViewport>
  <TimelineNavigator />
</Timeline>
```

Place it anywhere inside the timeline, outside the viewport. Dragging an edge zooms while holding the other edge in place, through `onZoomChange` with `reason: "drag"`; a double-click fits the whole timeline with `reason: "double-click"`.

## Musical time

The `musical-time` lib (`npx shadcn@latest add @audio/musical-time`) turns a tempo into what a timeline needs, in seconds:

- `gridInterval(division, zoom, tempo)` is the grid's step: a fixed division (`"1-bar"`, `"1/8"`, …), or `"adaptive"` for the finest division still 24px apart at this zoom. Pass `{ triplet: true }` for three in the space of two. Give the same number to `snapStep` and to the lanes' `gridStep`, so the lines you see are the places you land.
- `barLabelInterval(zoom, tempo)` is how far apart the ruler's bar numbers go: whole bars, spread out until they no longer collide.
- `barsBeatsAt(seconds, tempo)` and `describeBarsBeats` read a position as bars, beats and sixteenths.

## Placing your own parts

Every lane sets a `--timeline-unit` CSS variable, the width of one unit. Parts are placed with it, so anything you draw follows the zoom the same way:

```tsx
<div style={{ left: "calc(var(--timeline-unit) * 12)", position: "absolute" }} />
```

## API reference

### Root

Groups the parts of a timeline and owns what they share: its length, its zoom, its grid and the playback position. Units are yours: seconds, beats, pulses or steps. `zoom` is how many px one unit takes; leave it unset and the timeline fits the width it is given. The position comes from `position`, or from a live `source` that the playhead follows straight in the DOM without re-rendering React. With a `snapStep`, every gesture lands on the grid unless Cmd/Ctrl is held. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultPosition` | `number` | `0` | Uncontrolled starting position. |
| `defaultZoom` | `number` |  | Uncontrolled starting zoom, in px per unit. Unset, the timeline fits its width until zoomed. |
| `disabled` | `boolean` |  |  |
| `duration` | `number` | `1` | Length of the timeline, in your units. |
| `largeStep` | `number` |  | Step for Page Up/Page Down and Shift + arrow keys. Defaults to ten `step`s. |
| `maxZoom` | `number` | `Infinity` |  |
| `minZoom` | `number` | `0` |  |
| `onPositionChange` | `( value: number, eventDetails: PositionChangeEventDetails ) => void` |  | Fires while the position is moved: press, drag, keyboard and input changes. |
| `onPositionCommitted` | `( value: number, eventDetails: PositionCommitEventDetails ) => void` |  | Fires when a gesture that moved the position ends. |
| `onZoomChange` | `(zoom: number, eventDetails: ZoomChangeEventDetails) => void` |  | Fires when the zoom changes, already clamped. `eventDetails.cancel()` keeps the zoom where it was. |
| `position` | `number` |  | Playback position, from 0 to `duration`. |
| `snapOffset` | `number` | `0` | Where the grid's lines start, in your units. |
| `snapStep` | `number` | `0` | Distance between grid lines, in your units. 0 is no grid. |
| `source` | `Source` |  | A live position followed outside React; takes precedence over `position`. |
| `step` | `number` |  | Step for the arrow keys. Defaults to `snapStep`, or a hundredth of `duration`. |
| `zoom` | `number` |  | Zoom, in px per unit. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### Navigator

The whole timeline as one bar, with the stretch the viewport shows drawn inside it as `Timeline.NavigatorWindow`: drag the window to scroll, drag one of its `Timeline.NavigatorHandle`s to zoom, double-click to show everything. Place it anywhere inside `Timeline.Root`, outside the viewport. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `getAriaValueText` | `DescribePosition` |  | Returns how a position is announced by the window and its handles. Defaults to the number. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### NavigatorWindow

The stretch of the timeline the viewport shows. Dragging it scrolls; its native `<input type="range">` scrolls from the keyboard and carries its accessible name. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### NavigatorHandle

One edge of the window: dragging it zooms, holding the other edge in place. Its native `<input type="range">` does the same from the keyboard and carries its accessible name. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `edge` | `"end" \| "start"` |  | The edge of the window this handle moves. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### Viewport

The scrolling window onto the timeline. Cmd/Ctrl + wheel (and pinch on a trackpad) zooms around the pointer; a bare wheel scrolls as usual. Whatever changes the zoom, the point it was anchored on stays where it was, or the middle of the view when nothing named one. It reports its scroll offset and width for `Timeline.Navigator`. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### Lane

A strip along the timeline that its parts are placed on: a track, the ruler's strip, a row of markers. Zoomed, it is as long as the timeline; fitted, it takes the width it is given and the timeline is spread across it. Its `--timeline-unit` CSS variable is the width of one unit. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### Ruler

The lane that moves the position: a press jumps to the pointer and a drag scrubs, both on the grid unless Cmd/Ctrl is held; with Shift held the drag scrubs four times finer. It holds the native `<input type="range">` that takes focus, handles the keyboard and carries the accessible name (`aria-label` / `aria-labelledby`). Place `Timeline.Mark`s in it for its labels. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `getAriaValueText` | `DescribePosition` |  | Returns how the position is announced, e.g. `"bar 3, beat 2"`. Defaults to the number. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-fitted` | Whether no zoom is set, so the timeline fits the width it is given. |
| `data-scrubbing` | Whether a pointer is moving the position. |

### Range

A stretch of the timeline, such as a loop, a selection or a clip, laid on the lane it sits in from `value[0]` to `value[1]`. Dragging its body moves it, on the grid unless Cmd/Ctrl is held; add a `Timeline.RangeHandle` per edge to resize it. With `drawable`, dragging across empty lane draws a new range. Its own native `<input type="range">` moves it from the keyboard and carries its accessible name (`aria-label` / `aria-labelledby`). Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `Value` |  | Uncontrolled starting range. Defaults to the whole timeline. |
| `disabled` | `boolean` |  |  |
| `drawable` | `boolean` | `false` | Whether dragging across empty lane draws a new range. |
| `getAriaValueText` | `DescribePosition` |  | Returns how a position is announced, for the range and its handles. Defaults to the number. |
| `minLength` | `number` |  | The shortest the range can be, in the timeline's units. Defaults to the grid step. |
| `movable` | `boolean` | `true` | Whether dragging the body, or its keys, moves the range. |
| `onValueChange` | `(value: Value, eventDetails: ChangeEventDetails) => void` |  | Fires while the range is moved, resized or drawn. |
| `onValueCommitted` | `(value: Value, eventDetails: CommitEventDetails) => void` |  | Fires when a gesture that changed the range ends. |
| `value` | `Value` |  | The range, as `[start, end]` in the timeline's units. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is moving, resizing or drawing the range. |

### RangeHandle

| Prop | Type | Default | Description |
| --- | --- | --- | --- |

### Registry component

#### Timeline

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `duration` | `number` | `1` | Length of the timeline, in your units. |
| `zoom` | `number` | - | Controlled zoom, in px per unit. Unset, the timeline fits its width. |
| `defaultZoom` | `number` | - | Uncontrolled starting zoom. |
| `minZoom` / `maxZoom` | `number` | `0` / `Infinity` | Bounds the zoom is clamped to. |
| `onZoomChange` | `(zoom, eventDetails) => void` | - | Fires when the wheel or the navigator changes the zoom. `eventDetails.reason` is `"wheel"`, `"drag"`, `"keyboard"`, `"input-change"` or `"double-click"`; `eventDetails.cancel()` keeps the zoom. |
| `position` | `number` | - | Controlled playback position. |
| `defaultPosition` | `number` | `0` | Uncontrolled starting position. |
| `source` | `{ getSnapshot, subscribe }` | - | A live position followed outside React; takes precedence over `position`. |
| `onPositionChange` | `(value, eventDetails) => void` | - | Fires while the position is moved. `eventDetails.reason` is `"press"`, `"drag"`, `"keyboard"` or `"input-change"`. |
| `onPositionCommitted` | `(value, eventDetails) => void` | - | Fires when a gesture that moved the position ends. |
| `snapStep` | `number` | `0` | Distance between grid lines. `0` is no grid. |
| `snapOffset` | `number` | `0` | Where the grid's lines start. |
| `step` / `largeStep` | `number` | `snapStep` / ten steps | Keyboard steps. |
| `disabled` | `boolean` | `false` | Disables seeking and zooming. |

#### Parts

| Component | Role |
| --------- | ---- |
| `TimelineViewport` | The scrolling window. Zooms around the pointer with Cmd/Ctrl + scroll. `scrollbar="hidden"` drops the native scrollbar. |
| `TimelineRuler` | The lane that seeks. Holds the input; takes `aria-label` and `getAriaValueText`. |
| `TimelineLane` | A strip the timeline's parts are placed on. `gridStep` draws a line every that many units. |
| `TimelineMark` | Something placed at `value`: a bar number, a cue. |
| `TimelinePlayhead` | Follows the position on the lane it sits in. |
| `TimelineRange` | A stretch of the timeline: `value`, `defaultValue`, `minLength`, `movable`, `drawable`, `onValueChange`, `onValueCommitted`. |
| `TimelineRangeHandle` | Resizes one `edge` of the range. |
| `TimelineNavigator` | The whole timeline as one bar, scrolling and zooming the viewport. |

`@audio-ui/react/timeline` exposes the same parts as `Timeline.Root`, `Timeline.Viewport`, `Timeline.Ruler`, `Timeline.Lane`, `Timeline.Mark`, `Timeline.Playhead`, `Timeline.Range`, `Timeline.RangeHandle`, and `Timeline.Navigator` with its `Timeline.NavigatorWindow` and `Timeline.NavigatorHandle`. Every part accepts a `render` prop and `className` / `style` as functions of state, and exposes `data-disabled`, `data-fitted` and `data-scrubbing`.
