Piano for playing or displaying notes (a virtual instrument, a MIDI visualizer, a chord reference). The registry component wraps `Piano` primitives from `@audio-ui/react` and renders classic white/black key layout for any MIDI note range.

## Overview

- **Range:** `minPitch` / `maxPitch` are MIDI pitches (defaults `48`/`72`, C3 to C5), or `pitches` lists exactly the keys to show. Key color (white/black) and layout follow the chromatic pattern.
- **Events:** `onNoteOn(pitch, eventDetails)` / `onNoteOff(pitch, eventDetails)` fire the MIDI pitch, which is what an audio engine consumes. `eventDetails.reason` says how (`"press"`, `"glide"`, `"keyboard"`), and `eventDetails.cancel()` in `onNoteOn` keeps the key silent.
- **Interaction model:** Press and hold a key to sustain the note. Drag across keys (mouse) for a glissando — each key retriggers as the pointer crosses it. Multiple simultaneous pointers (multi-touch) each independently hold their own key — true polyphony.
- **External notes:** An optional controlled `activeNotes` prop lights up keys from outside pointer interaction (a MIDI input device, a sequencer's current chord) without affecting `onNoteOn`/`onNoteOff`.
- **Accessibility:** Every key is a button named after its pitch ("C4"), behind one roving tab stop. Arrow keys move between keys, and `Space` or `Enter` holds the focused key down until released.
- **Layout:** The primitive also lays keys out vertically (`orientation="vertical"`, low end at the bottom) and evenly (`layout="even"`, one equal share per key). The piano roll's keyboard is built that way.

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { Piano } from "@audio-ui/react";

<Piano.Root>
  <Piano.Keys>
    {(pitch) => (
      <Piano.Key pitch={pitch}>
        <Piano.KeyLabel />
      </Piano.Key>
    )}
  </Piano.Keys>
</Piano.Root>
```

## Usage

```tsx
import { Piano } from "@/components/audio/piano";
```

**Note events:**

```tsx
<Piano
  maxPitch={72}
  minPitch={48}
  onNoteOff={(pitch) => synth.release(pitch)}
  onNoteOn={(pitch) => synth.trigger(pitch)}
/>
```

**External notes (MIDI input, a sequencer's current chord):**

```tsx
<Piano activeNotes={midiInputNotes} maxPitch={72} minPitch={48} />
```

## API reference

### Root

A keyboard to play: every key sounds while pressed, by pointer or from the keyboard. Dragging across the keys glides from one to the next, and each pointer holds its own key, so chords can be played on a touch screen. It is laid out like a piano, or with `layout="even"` as one equal share per key, the way a piano roll's rows are; `orientation="vertical"` puts the low end at the bottom. The keys are one tab stop, walked with the arrow keys. Renders a `<div>` element.

<TypeRow name={"activeNotes"} type={"readonly number[]"}>Pitches lit from elsewhere, such as a MIDI input or a sequencer, on top of the keys pressed here.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>
<TypeRow name={"layout"} type={"Layout"} default={"\"keyboard\""}>How the keys share the length: like a piano, or one equal share each.</TypeRow>
<TypeRow name={"maxPitch"} type={"number"} default={"72"}>Highest MIDI pitch, inclusive.</TypeRow>
<TypeRow name={"minPitch"} type={"number"} default={"48"}>Lowest MIDI pitch, inclusive: 60 is middle C.</TypeRow>
<TypeRow name={"onNoteOff"} type={"(pitch: number, eventDetails: NoteOffEventDetails) => void"}>Fires when a key is released, the pointer glides off it, or it loses focus while held.</TypeRow>
<TypeRow name={"onNoteOn"} type={"(pitch: number, eventDetails: NoteOnEventDetails) => void"}>Fires when a key is pressed or glided onto. `eventDetails.cancel()` keeps it silent.</TypeRow>

### Keys

Renders `children` once per key, lowest first: the place to put a `Piano.Key` for each pitch. Renders no element of its own.

<TypeTable>
<TypeRow name={"children"} type={"(pitch: number) => React.ReactNode"}></TypeRow>

### Key

One key, placed along the keyboard for its pitch. It sounds while pressed: by pointer through the keyboard, or with Enter or Space while focused. Its accessible name defaults to the pitch, such as "C4". Renders a `<button>` element.

<TypeTable>
<TypeRow name={"pitch"} type={"number"}>The MIDI pitch this key plays.</TypeRow>
</TypeTable>

<TypeTable title="Data attributes">

<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
</TypeTable>

### KeyLabel

The name of the key it sits in, such as "C4". Hidden from assistive technology, which reads the key's own name. Renders a `<span>` element.

<TypeTable title="Data attributes">
