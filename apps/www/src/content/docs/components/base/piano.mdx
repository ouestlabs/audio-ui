Piano for playing or displaying notes (a virtual instrument, a MIDI visualizer, a chord reference). The registry component wraps `Piano` primitives from `@audio-ui/react` and renders classic white/black key layout for any MIDI note range.

## Overview

- **Range:** `minPitch` / `maxPitch` are MIDI pitches (defaults `48`/`72`, C3 to C5), or `pitches` lists exactly the keys to show. Key color (white/black) and layout follow the chromatic pattern.
- **Events:** `onNoteOn(pitch, eventDetails)` / `onNoteOff(pitch, eventDetails)` fire the MIDI pitch, which is what an audio engine consumes. `eventDetails.reason` says how (`"press"`, `"glide"`, `"keyboard"`), and `eventDetails.cancel()` in `onNoteOn` keeps the key silent.
- **Interaction model:** Press and hold a key to sustain the note. Drag across keys (mouse) for a glissando — each key retriggers as the pointer crosses it. Multiple simultaneous pointers (multi-touch) each independently hold their own key — true polyphony.
- **External notes:** An optional controlled `activeNotes` prop lights up keys from outside pointer interaction (a MIDI input device, a sequencer's current chord) without affecting `onNoteOn`/`onNoteOff`.
- **Accessibility:** Every key is a button named after its pitch ("C4"), behind one roving tab stop. Arrow keys move between keys, and `Space` or `Enter` holds the focused key down until released.
- **Layout:** The primitive also lays keys out vertically (`orientation="vertical"`, low end at the bottom) and evenly (`layout="even"`, one equal share per key). The piano roll's keyboard is built that way.

## Usage

```tsx
import { Piano } from "@/components/audio/piano";
```

**Note events:**

```tsx
<Piano
  maxPitch={72}
  minPitch={48}
  onNoteOff={(pitch) => synth.release(pitch)}
  onNoteOn={(pitch) => synth.trigger(pitch)}
/>
```

**External notes (MIDI input, a sequencer's current chord):**

```tsx
<Piano activeNotes={midiInputNotes} maxPitch={72} minPitch={48} />
```

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Press a key** | Fires `onNoteOn`; the key stays pressed while held. |
| **Release** | Fires `onNoteOff`. |
| **Drag across keys** | Glissando — the previous key releases (`onNoteOff`) and the new one triggers (`onNoteOn`) as the pointer crosses it. |
| **Multiple pointers** | Each pointer (finger) independently holds its own key — true polyphony on touch devices. |

### Keyboard

One tab stop for the whole keyboard; focus then roves between keys:

| Key | Action |
| --- | ------ |
| `ArrowLeft` / `ArrowRight` (or `ArrowDown` / `ArrowUp`) | Move focus to the next lower / higher key |
| `Shift` + arrow, `PageDown` / `PageUp` | Move focus an octave down / up |
| `Space` / `Enter` | Hold the focused key: `onNoteOn` on press, `onNoteOff` on release |
| `Home` / `End` | Move focus to the lowest / highest key |

## API reference

`Piano` accepts style props (`size`, `className`) plus primitive props from `PianoPrimitive.Root.Props`.

### Value and state

| Prop            | Type                  | Default | Description                                                      |
| --------------- | ---------------------- | ------- | ------------------------------------------------------------------ |
| `minPitch`      | `number`               | `48`    | Lowest MIDI pitch on the keyboard.                                |
| `maxPitch`      | `number`               | `72`    | Highest MIDI pitch on the keyboard.                               |
| `pitches`       | `number[]`             | -       | Exactly these pitches, in place of `minPitch`…`maxPitch`.         |
| `activeNotes`   | `number[]`              | -       | Pitches lit from outside pointer interaction. Merged with the pressed keys for display. |
| `disabled`      | `boolean`               | `false` | Whether the keyboard is disabled.                                 |
| `onNoteOn`      | `(pitch: number, eventDetails) => void` | -     | Fires when a key is pressed or glided onto. `eventDetails.cancel()` keeps it silent. |
| `onNoteOff`     | `(pitch: number, eventDetails) => void` | -     | Fires when a key is released, glided off, or loses focus while held. |
| `aria-label`    | `string`                | -       | Accessible name for the keyboard.                                 |
| `aria-labelledby` | `string`              | -       | ID of a labeling element.                                         |

### Layout and display

| Prop        | Type                          | Default     | Description                        |
| ----------- | ------------------------------ | ----------- | ----------------------------------- |
| `size`      | `"sm" \| "default" \| "lg"`   | `"default"` | Size variant (sets the keyboard height). |
| `className` | `string`                      | -           | Additional CSS classes.            |

Additional valid HTML attributes passed to `Piano.Root` are forwarded.
