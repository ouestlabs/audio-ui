Triggers sounds, for a drum machine, a sampler or a clip launcher. The registry component is written on the pad primitive, which installs with it, and lays the pads out in a grid of `columns`.

</ForFrameworks>

<ForFrameworks only="vue svelte web">

The pad grid's behavior is one file, the primitive, written on the UI SDK kernel and copied into your project. A pad sounds while it is held, by pointer or from the keyboard. Each framework renders it with a thin adapter that you also own, and one suite of tests runs against each adapter.

</ForFrameworks>

## Overview

- **Events:** `onPadOn(value, eventDetails)` and `onPadOff(value, eventDetails)` report the pad's `value`, ready for an audio engine. `eventDetails.velocity` says how hard it was struck, from 0 to 1, and `eventDetails.cancel()` in `onPadOn` keeps the pad silent.
- **Velocity:** a pen or a pressure-sensitive screen strikes as hard as it presses. Other pointers strike harder toward the top of the pad. The keyboard strikes at `0.8`. Each pad exposes its last velocity as `--pad-velocity`, so the flash can follow it.
- **Choke groups:** pads sharing a `chokeGroup` stop each other, like a closed hihat cutting an open one. Striking one fires `onPadOff` with `reason: "choke"` for the last pad struck in its group, held or still ringing.
- **Pointer:** each pointer holds its own pad, so several play at once on a touch screen. Sliding off a pad does not strike the next one.
- **External pads:** `activePads` lights pads from outside, such as the steps of a sequencer, without calling `onPadOn` or `onPadOff`.
- **Accessibility:** each pad is a button named by its content, behind one tab stop. The arrow keys move between pads, and Space or Enter holds the focused pad until it is released.

## Usage

<ForFrameworks only="react">

```tsx
import { Pad, PadItem } from "@/components/audio-ui/pad";
```

**Pad events:**

```tsx
<Pad
  aria-label="Drum pads"
  columns={2}
  onPadOn={(value, { velocity }) => sampler.trigger(value, velocity)}
>
  <PadItem value="kick">Kick</PadItem>
  <PadItem value="snare">Snare</PadItem>
</Pad>
```

**Choke groups (a closed hat cuts the open one):**

```tsx
<Pad
  aria-label="Hats"
  columns={2}
  onPadOff={(value, { reason }) => {
    if (reason === "choke") {
      sampler.stop(value);
    }
  }}
  onPadOn={(value, { velocity }) => sampler.trigger(value, velocity)}
>
  <PadItem chokeGroup="hat" value="closed-hat">
    Closed hat
  </PadItem>
  <PadItem chokeGroup="hat" value="open-hat">
    Open hat
  </PadItem>
</Pad>
```

In the web adapter, an Item wraps the button: the button inside it is the pad. The two callbacks are the `padon` and `padoff` events.

### What a strike reports

- `onPadOn` gets `velocity` from 0 to 1, a `reason` (`"press"` or `"keyboard"`), a `source` (`"mouse"`, `"touch"`, `"pen"` or `"keyboard"`) and the `event`.
- `onPadOff` gets a `reason`: `"press"`, `"keyboard"`, or `"choke"` when another pad of its group cut it.

## API reference

<ForFrameworks only="react">

### Registry component

`Pad` accepts `className` and `style` plus the props of the `Pad` primitive's Root, and sets the grid's columns from `columns`. `PadItem` accepts the props of the primitive's `Pad.Item`.

Additional valid HTML attributes passed to `Pad.Root` and `Pad.Item` are forwarded.

</ForFrameworks>

### Options

Set on the Root, as props (an attribute in kebab case in the web adapter).

| Option | Type | Default | |
| --- | --- | --- | --- |
| `columns` | `number` | `4` | How many pads a row holds: what the up and down arrows move by. Lay the grid out to match. |
| `activePads` | `string[]` | | Pads lit from elsewhere, such as a sequencer or a MIDI input, on top of the ones held here. |
| `disabled` | `boolean` | `false` | Strikes nothing. |
| `onPadOn` | `(value, details) => void` | | A pad is struck. `details.cancel()` keeps it silent. |
| `onPadOff` | `(value, details) => void` | | A pad is released, loses focus while held, or is choked. |

An Item takes its `value`, a `disabled`, and a `chokeGroup`: pads that share one stop each other, so striking one stops the last one struck, held or still ringing, as an open and a closed hi-hat do.

### States to style from

- `data-active` on a pad while it sounds, held here or listed in `activePads`, and `data-disabled` on the Root and the pads.
- `--pad-velocity` on a pad, from 0 to 1: how hard it was last struck, for a flash that follows the force.
