An audio value as a DAW shows it, in monospace figures that do not jump as they change: `120.00 BPM`, `-6.0 dB`, `1.2 kHz`, `L30`, `50 %`, `+3 st`, `1:02.345`.

## Installation

<Install name="value-display" packages="@audio-ui/core class-variance-authority" />

## Usage

```tsx
import { formatValue, ValueDisplay } from "@/components/audio-ui/value-display";

<ValueDisplay kind="db" label="Gain" value={gain} />

// The same text, for a title or an announcement.
formatValue(gain, "db");
```

| `kind` | Value | Reads |
| --- | --- | --- |
| `bpm` | beats per minute | `120.00 BPM` |
| `db` | decibels, `-Infinity` for silence | `-6.0 dB`, `-∞ dB` |
| `hz` | hertz | `440 Hz`, `1.2 kHz` |
| `pan` | -1 to 1 | `L30`, `C`, `R100` |
| `percent` | 0 to 1 | `50 %` |
| `semitones` | semitones | `+3 st` |
| `time` | seconds | `1:02.345` |
