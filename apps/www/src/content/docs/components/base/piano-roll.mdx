A piano roll for writing a phrase: a keyboard down the side, notes on a grid, a velocity bar under each note. It sits inside a [Timeline](/docs/components/base/timeline), so notes start and last in the timeline's units, snap to its grid and follow its zoom.

## Overview

- **Notes:** press on the grid to draw one (or start a selection rectangle), drag to move it, drag an edge to resize, double-click to delete. Whatever is selected moves and resizes together.
- **Keys:** the keyboard on the side plays a note when pressed; the rows light up for the pitches playing.
- **Velocity:** a bar per note in its own lane, drawn from the bottom.
- **Keyboard:** every edit works without a pointer, and copy, paste, duplicate and quantize are one key away.
- **Accessibility:** each note is a toggle button named after its pitch and span; each velocity bar holds a native `<input type="range">`.

## Anatomy

Import the registry components for the ready-made look, or compose the primitive's parts yourself.

```tsx
import { PianoRoll, Timeline } from "@audio-ui/react";

<Timeline.Root duration={16} snapStep={1}>
  <PianoRoll.Root>
    <PianoRoll.Keys>
      <PianoRoll.Rows>
        {(pitch) => (
          <PianoRoll.Key pitch={pitch}>
            <PianoRoll.KeyLabel />
          </PianoRoll.Key>
        )}
      </PianoRoll.Rows>
    </PianoRoll.Keys>
    <PianoRoll.Grid aria-label="Notes">
      <PianoRoll.Rows>{(pitch) => <PianoRoll.Row pitch={pitch} />}</PianoRoll.Rows>
      <PianoRoll.Notes>
        {(note) => (
          <PianoRoll.Note key={note.id} note={note}>
            <PianoRoll.NoteHandle edge="start" />
            <PianoRoll.NoteHandle edge="end" />
          </PianoRoll.Note>
        )}
      </PianoRoll.Notes>
      <PianoRoll.Marquee />
    </PianoRoll.Grid>
    <PianoRoll.VelocityLane aria-label="Velocity">
      <PianoRoll.Notes>
        {(note) => <PianoRoll.Velocity key={note.id} note={note} />}
      </PianoRoll.Notes>
    </PianoRoll.VelocityLane>
  </PianoRoll.Root>
</Timeline.Root>;
```

## Usage

```tsx
import { Timeline, TimelineNavigator } from "@/components/audio/elements/timeline";
import {
  PianoRoll,
  PianoRollGrid,
  PianoRollKeys,
  PianoRollStrip,
  PianoRollVelocity,
  PianoRollVelocityScale,
  PianoRollViewport,
} from "@/components/audio/elements/piano-roll";

<Timeline duration={16} snapStep={1}>
  <PianoRoll
    className="h-96"
    maxPitch={72}
    minPitch={48}
    onNoteOn={(pitch, details) => play(pitch, details.velocity)}
    onValueChange={setNotes}
    value={notes}
  >
    <PianoRollViewport>
      <PianoRollStrip className="flex-1" lead={<PianoRollKeys />}>
        <PianoRollGrid aria-label="Notes" gridStep={1} />
      </PianoRollStrip>
      <PianoRollStrip lead={<PianoRollVelocityScale />} sticky="bottom">
        <PianoRollVelocity />
      </PianoRollStrip>
    </PianoRollViewport>
  </PianoRoll>
</Timeline>;
```

A note is `{ id, pitch, start, length, velocity? }`: `pitch` is a MIDI number (60 is middle C), `start` and `length` are in the timeline's units, and `velocity` is 0 to 1 (full when left out). `value` and `selection` are controlled; `defaultValue` and `defaultSelection` leave them to the roll. The roll reports every edit through `onValueChange` and, when a gesture or a key press ends, `onValueCommitted`; `eventDetails.edit` tells what happened (`"add"`, `"move"`, `"resize"`, `"remove"`, `"duplicate"`, `"paste"`, `"quantize"` or `"velocity"`) and `eventDetails.cancel()` keeps the notes as they were.

`onNoteOn` and `onNoteOff` say when a pitch should sound or stop: a key pressed, a note drawn, picked up or moved to a new pitch. A MIDI file can be read and written with the `midi` library (`@audio/midi`); the preview above imports and exports `.mid` files with it.

## Interaction

### Pointer

| Gesture | What it does |
| --- | --- |
| Press on empty grid | With `mode="draw"`, draws a note whose end follows the pointer. With `mode="select"`, starts a selection rectangle (a double-click draws). `Shift` adds to the selection. |
| Drag a note | Moves it, with the selection when it is part of it. On the grid unless <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> is held. |
| `Alt` + drag a note | Moves a copy. |
| Drag a note's edge | Resizes it: the end changes the length, the start trims it from the front. |
| `Shift` + click a note | Toggles it in the selection. |
| Double-click a note | Deletes it. |
| Drag a velocity bar | Changes the velocity of the selection by the same amount. |
| Press a key | Plays it; with `Shift`, selects every note on its row. |

### Keyboard

| Key | What it does |
| --- | --- |
| Arrow keys on a note | `Left` / `Right` move it by a grid step, `Up` / `Down` by a semitone. With `Shift`: resize it, or move an octave. |
| `Enter`, `Space` on a note | Toggle it in the selection. |
| `Delete`, `Backspace` | Remove the selected notes. |
| `Enter` on the grid | Adds a note at the playback position. |
| `Escape`, <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + `A` | Clear the selection, select every note. |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + `D` | Repeat the selection right after itself and select the copies. |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + `C`, `X`, `V` | Copy, cut, and paste at the playback position. |
| `Q` | Snap the starts of the selection (every note, with none selected) to the grid. |
| Arrow keys, `Page Up` / `Down`, `Home` / `End` on a velocity bar | Change the velocity by 5%, by 25%, or to silent or full. |

### Keys

The keyboard down the side: a `Piano` laid out on the roll's rows, low end at the bottom. Pressing a key sounds it through the roll's `onNoteOn`; with Shift, pressing it (or Shift + Enter) selects every note on its row, or deselects them when they all are. Put a `PianoRoll.Key` per row inside, with `PianoRoll.Rows`. Renders a `<div>` element.

### Rows

Renders `children` once per row, from the highest pitch down: the place to put a `PianoRoll.Key` or a `PianoRoll.Row`. Renders no element of its own.

<TypeTable>
<TypeRow name={"children"} type={"(pitch: number) => React.ReactNode"}></TypeRow>
</TypeTable>

### Key and KeyLabel

The same parts as [Piano](/docs/components/base/piano): a key of the keyboard, and its label.

### Grid

The surface notes are drawn on: a timeline lane, with the roll's rows stacked down it. A press on empty grid draws a note (`mode="draw"`), whose end then follows the pointer, or starts a selection rectangle, Shift adding to what is selected; in that mode a double-click draws. Focused, Enter adds a note at the playback position, Escape clears the selection and Cmd/Ctrl+A selects every note. From the grid or a note, Cmd/Ctrl+D repeats the selection right after itself, Cmd/Ctrl+C, X and V copy, cut and paste at the playback position, and Q snaps the starts of the selection (every note, with none selected) to the grid. Renders a `<div>` element.

### Row

The band a pitch takes across the grid, for shading black-key rows or ruling where an octave starts. It lets presses through to the grid and is hidden from assistive technology. Renders a `<div>` element.

<TypeRow name={"pitch"} type={"number"}>The MIDI pitch of the row.</TypeRow>
</TypeTable>

<TypeRow name={"data-color"}>`"black"` or `"white"`.</TypeRow>
<TypeRow name={"data-folded"}>Whether the roll is folded.</TypeRow>
<TypeRow name={"data-octave"}>Whether the row is a C, where an octave starts.</TypeRow>

### Notes

Renders `children` once per note, in the order they are read: by start, then from the highest pitch down. That order is also the tab order. Renders no element of its own.

<TypeTable>
<TypeRow name={"children"} type={"(note: Note) => React.ReactNode"}></TypeRow>
</TypeTable>

### Note

One note, placed on its row from its start, as long as its length. A toggle button named after its pitch and span (`getNoteLabel` on `Root`). Renders a `<div>` element.

<TypeTable>
<TypeRow name={"note"} type={"Note"}>The note to show; while it is being edited, the roll shows it where the edit has it.</TypeRow>
</TypeTable>

<TypeTable title="Data attributes">
<TypeRow name={"data-selected"}>Whether the note is in the selection: also `aria-pressed`.</TypeRow>
<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
</TypeTable>

### NoteHandle

One edge of the note it sits in, dragged to change the note's length: the end makes it longer or shorter, the start trims it from the front while its end stays put. On the grid unless Cmd/Ctrl is held, and for the whole selection when the note is part of it. Shift + Left and Right on the note do the same from the keyboard, so the handle is hidden from assistive technology. Renders a `<div>` element.

<TypeTable>
<TypeRow name={"edge"} type={"\"start\" | \"end\""}>The edge of the note this handle drags.</TypeRow>
</TypeTable>

### Marquee

The selection rectangle being dragged across the grid; renders nothing the rest of the time. Hidden from assistive technology. Renders a `<div>` element.

### VelocityLane

A strip under the grid where each note's velocity stands as a bar, placed at the note's start: a timeline lane, like the grid. Put a `PianoRoll.Velocity` per note inside, with `PianoRoll.Notes`. Renders a `<div>` element.

### Velocity

One note's velocity, as a bar from the bottom of the lane: its height is the velocity, through the `--piano-roll-velocity` CSS variable. Dragging it up or down changes the velocity of the selection by the same amount when the note is part of it, so a phrase keeps its dynamics; Shift + click toggles the note in the selection. A native `<input type="range">` inside takes the arrow keys and carries the accessible name, which defaults to the note's. The velocity set last is what the next drawn note gets. Renders a `<div>` element.

<TypeTable>
<TypeRow name={"note"} type={"Note"}>The note whose velocity this is.</TypeRow>
<TypeRow name={"getAriaValueText"} type={"(velocity: number) => string"}>Returns how a velocity, 0…1, is announced. Defaults to a percentage.</TypeRow>
</TypeTable>

### Registry components

`PianoRoll` takes the `Root` props. The rest lay the editor out on two columns, the keys' and the timeline's:

| Component | Description |
| --- | --- |
| `PianoRollViewport` | Scrolls the roll both ways, without scrollbars: put a `TimelineNavigator` above it to scroll and zoom across. |
| `PianoRollStrip` | A row of the editor: `lead` in the keys' column, stuck to the left edge, the lanes in `children` beside it. `sticky` keeps it at the `"top"` or `"bottom"` of the viewport. |
| `PianoRollKeys` | The keyboard down the side, one key per row. `size` is `"sm"`, `"default"` or `"lg"`. |
| `PianoRollGrid` | The notes, on their rows. `gridStep` draws a line every step, `accentStep` a firmer one, such as each beat; anything placed on the timeline, such as a `TimelinePlayhead`, goes in `children`. |
| `PianoRollVelocity` | Each note's velocity as a bar. |
| `PianoRollVelocityScale` | The scale beside the velocity lane, for the `lead` of its strip. |
