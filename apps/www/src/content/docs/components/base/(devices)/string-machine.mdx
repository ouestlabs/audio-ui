A string machine. Every key sounds four registers, a violin and a viola at its pitch, a cello an octave down and a bass two, each at its own level. The sum bows in slowly and lets go slowly, through a brightness filter, then an ensemble: three delay lines swayed by three slow oscillators a third of a turn apart, which thicken the sound as a section of players does. Start from one of its eight presets (Strings, Violins, Cellos, Full, Swell, Pizz, Dark, Choir), then shape it. It is a [device](/docs/devices): a state, a panel, an engine and tools, each its own file.

Every control reads 0 to 10, as a panel's sliders do, and shows the value it sets in the unit the sound takes.

## Panel

The panel loads a preset from the menu in its title bar, lays the other controls out by what they do (registers, tone, bow, output) and has a keyboard of two octaves that plays the machine. `stringMachinePreset(name)` gives a preset's whole state, and `STRING_MACHINE_PRESETS` lists them. With `activeNotes`, the notes held now, such as on a MIDI keyboard, light up their keys. The panel sends notes out and does not make the sound, so it plays through any engine.

## Engine

Create it, connect it and update it as for any device: see [The engine](/docs/devices#the-engine).

```ts
engine.noteOn({ frequency: 261.63, velocity: 0.8 }); // bows a note in
engine.noteOff(); // lets it go, over the release

// Scheduled ahead on the audio clock, by a host that plays notes from a song:
engine.noteOn({ frequency: 440 }, { at: time, id: "a4" });
engine.noteOff({ at: time + length, id: "a4" });
```

An engine plays one voice, through its own ensemble. For chords, give each note an engine of its own: [`usePolyphony`](/docs/guides/synthesis#polyphony) keeps eight for the block above, and the [arrangement](/docs/components/base/arrangement)'s engine does it for a MIDI track. A note bows in over its attack and lets go over the release from where it had got to, so a short note never clicks; a harder key leans on the level a little, as a bow does. A note while one is held cuts it and bows anew, and a `noteOff` whose `id` is not the held note's lets nothing go. A register's level and the brightness move a held note. An agent plays the machine with the `play` tool.
