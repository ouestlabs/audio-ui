XY pad for simultaneous control of two values (for example filter cutoff/resonance, pan/mix, or macro controls). The registry component wraps `XYPad` primitives from `@audio-ui/react` and provides ready-to-use visuals (grid, crosshair, cursor, value display).

## Overview

- **Interaction model:** Press or drag on the pad, wheel / trackpad, and keyboard over both axes.
- **Axes:** Independent ranges and steps for X (`minX`, `maxX`, `stepX`) and Y (`minY`, `maxY`, `stepY`).
- **Feedback:** Grid lines, crosshair, cursor, and optional value display overlay. The value position is exposed as the CSS variables `--xy-pad-x` (from the left) and `--xy-pad-y` (from the top).
- **Accessibility:** The cursor holds one native `<input type="range">` per axis. Both carry the accessible name (`aria-label` becomes "… X" / "… Y", or name each axis with `getAriaLabel` on the primitive's `Thumb`); the X input takes focus and the arrow keys move both axes.

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { XYPad } from "@audio-ui/react";

<XYPad.Root>
  <XYPad.Label />
  <XYPad.Control>
    <XYPad.Thumb />
  </XYPad.Control>
  <XYPad.Value />
</XYPad.Root>
```

## Usage

```tsx
import { XYPad } from "@/components/audio/xypad";
```

**Uncontrolled** - initial value only:

```tsx
<XYPad
  defaultValue={{ x: 0, y: 0 }}
  maxX={100}
  maxY={1}
  minX={-100}
  minY={-1}
  stepX={1}
  stepY={0.01}
/>
```

**Controlled** - drive value from state:

```tsx
const [position, setPosition] = useState({ x: 50, y: 50 });

<XYPad
  maxX={100}
  maxY={100}
  minX={0}
  minY={0}
  onValueChange={setPosition}
  onValueCommitted={(value, details) => console.log("Committed:", value, details.reason)}
  value={position}
/>
```

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Press / drag on pad** | A press jumps the value to the pointer; a drag follows it. Reported as `eventDetails.reason` `"press"` then `"drag"`. |
| **Clamping** | Values always clamp to the configured axis ranges and snap to `stepX` / `stepY`. |
| **Commit event** | `onValueCommitted` fires when a gesture that changed the value ends. |
| **Lagging value** | While dragging, the cursor follows the pointer even if a controlled `value` updates late. Reject a value with `eventDetails.cancel()`. |

### Keyboard

On the focused pad:

| Key | Action |
| --- | ------ |
| `ArrowLeft` / `ArrowRight` | Decrease / increase X by `stepX` |
| `ArrowUp` / `ArrowDown` | Increase / decrease Y by `stepY` |
| `Shift` + arrow | Move by 10 steps |
| `PageUp` / `PageDown` | Increase / decrease Y by `stepY × 10` |
| `Home` / `End` | X to `minX` / `maxX` |

### Wheel

Wheel and trackpad input over the pad moves the point by the scrolled distance: scrolling up raises Y, scrolling right raises X. Reported as `eventDetails.reason === "wheel"`.

## API reference

### Root

Groups all parts of the pad and owns its two-dimensional value. Exposes the value position as CSS variables for crosshairs and guides: `--xy-pad-x` (from the left) and `--xy-pad-y` (from the top), as percentages. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `Point` |  | Uncontrolled starting value. Defaults to the center of the pad. |
| `disabled` | `boolean` |  |  |
| `format` | `Intl.NumberFormatOptions` |  | Formats each axis for `XYPad.Value` and the inputs' `aria-valuetext`. |
| `locale` | `Intl.LocalesArgument` |  |  |
| `maxX` | `number` | `100` |  |
| `maxY` | `number` | `100` |  |
| `minX` | `number` | `0` |  |
| `minY` | `number` | `0` |  |
| `onValueChange` | `(value: Point, eventDetails: ChangeEventDetails) => void` |  | Fires on every change: press, drag, keyboard, wheel and input changes. |
| `onValueCommitted` | `(value: Point, eventDetails: CommitEventDetails) => void` |  | Fires when an interaction ends with a new value. |
| `stepX` | `number` | `1` |  |
| `stepY` | `number` | `1` |  |
| `value` | `Point` |  |  |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging on the pad. |

### Control

The pad surface: a press jumps the value to the pointer and a drag follows it; the mouse wheel / trackpad moves it too. Sets `touch-action: none` so touch drags don't scroll the page. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging on the pad. |

### Thumb

Marks the value on the pad (`left`/`top` as percentages, centered with `translate`). Holds two native `<input type="range">`s, one per axis: the X input takes focus, both carry the accessible name, and the arrow keys move both axes. Renders a `<div>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `getAriaLabel` | `(axis: Axis) => string` |  | Names each axis input. Defaults to `aria-label` followed by "X" / "Y". |
| `getAriaValueText` | `( formattedValue: string, value: number, axis: Axis ) => string` |  | Returns an axis input's `aria-valuetext`. Defaults to the formatted value. |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging on the pad. |

### Value

The formatted value (`format`/`locale` on Root), `"x, y"` by default. Renders a `<output>` element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `\| React.ReactNode \| (( formattedX: string, formattedY: string, value: Point ) => React.ReactNode)` |  |  |

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging on the pad. |

### Label

Accessible label, associated with both axis inputs. Renders a `<div>` element.

| Data attribute | Description |
| --- | --- |
| `data-disabled` | Present when disabled. |
| `data-dragging` | Whether a pointer is dragging on the pad. |

### Registry component

`XYPad` accepts style props (`size`, `formatValue`, `valueDisplay`, `className`) plus primitive props from `XYPadPrimitive.Root.Props`. `aria-label`, `aria-labelledby`, and `aria-describedby` are forwarded to the axis inputs.

#### Value and state

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `value` | `{ x: number; y: number }` | - | Controlled value. |
| `defaultValue` | `{ x: number; y: number }` | center | Uncontrolled starting value. |
| `minX` / `maxX` | `number` | `0` / `100` | X range. |
| `minY` / `maxY` | `number` | `0` / `100` | Y range. |
| `stepX` / `stepY` | `number` | `1` | Step per axis. |
| `disabled` | `boolean` | `false` | Disables pointer, wheel, and keyboard. |
| `format` | `Intl.NumberFormatOptions` | - | Formats each axis for the value display and the inputs' value text. |
| `locale` | `Intl.LocalesArgument` | runtime | Locale used by `format`. |
| `onValueChange` | `(value, eventDetails) => void` | - | Every change. `eventDetails.reason` is `"press"`, `"drag"`, `"keyboard"`, `"wheel"`, or `"input-change"`; call `eventDetails.cancel()` to reject it. |
| `onValueCommitted` | `(value, eventDetails) => void` | - | When an interaction that changed the value ends. |
| `aria-label` | `string` | - | Accessible name for the pad's inputs. |
| `aria-labelledby` | `string` | - | ID of a labeling element. |

#### Layout and display

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `size` | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` | Size variant (affects height). |
| `formatValue` | `(value: { x: number; y: number }) => React.ReactNode` | - | Custom formatter for the value display. |
| `valueDisplay` | `"visible" \| "hidden"` | `"visible"` | Use `"hidden"` to hide the overlay. |
| `className` | `string` | - | Classes for the pad surface. |



`@audio-ui/react/xypad` exposes `XYPad.Root`, `XYPad.Control` (the pad surface), `XYPad.Thumb` (positioned at the value, holds the axis inputs), `XYPad.Value` (formatted `<output>`), and `XYPad.Label`. Every part accepts a `render` prop, `className` / `style` as functions of state, and exposes `data-disabled` / `data-dragging`. Draw grids and crosshairs with your own elements and the `--xy-pad-x` / `--xy-pad-y` variables.
