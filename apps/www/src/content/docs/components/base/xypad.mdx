Controls two values at once, such as filter cutoff and resonance, pan and mix, or two macros. The registry component wraps the `XYPad` primitive from `@audio-ui/react` and adds a grid, a crosshair, a cursor and a value display.

## Overview

- **Input:** press or drag on the pad, or use the mouse wheel, a trackpad or the keyboard, on both axes.
- **Axes:** X and Y have their own range and step (`minX`, `maxX`, `stepX`; `minY`, `maxY`, `stepY`).
- **Display:** grid lines, a crosshair, a cursor and an optional value display. The position is exposed as the CSS variables `--xy-pad-x` (from the left) and `--xy-pad-y` (from the top).
- **Accessibility:** the cursor holds one native `<input type="range">` per axis. Both carry the accessible name (`aria-label` becomes "… X" and "… Y", or set each with `getAriaLabel` on the primitive's `Thumb`). The X input takes focus, and the arrow keys move both axes.

## Anatomy

Import the primitive and assemble its parts.

```tsx
import { XYPad } from "@audio-ui/react";

<XYPad.Root>
  <XYPad.Label />
  <XYPad.Control>
    <XYPad.Thumb />
  </XYPad.Control>
  <XYPad.Value />
</XYPad.Root>
```

## Usage

```tsx
import { XYPad } from "@/components/audio/xypad";
```

**Uncontrolled** - initial value only:

```tsx
<XYPad
  defaultValue={{ x: 0, y: 0 }}
  maxX={100}
  maxY={1}
  minX={-100}
  minY={-1}
  stepX={1}
  stepY={0.01}
/>
```

**Controlled** - drive value from state:

```tsx
const [position, setPosition] = useState({ x: 50, y: 50 });

<XYPad
  maxX={100}
  maxY={100}
  minX={0}
  minY={0}
  onValueChange={setPosition}
  onValueCommitted={(value, details) => console.log("Committed:", value, details.reason)}
  value={position}
/>
```

## Interaction

### Pointer

<KeyTable title="Behavior">
<KeyRow gesture={"Press / drag on pad"}>A press jumps the value to the pointer; a drag follows it. Reported as `eventDetails.reason` `"press"` then `"drag"`.</KeyRow>
<KeyRow gesture={"Clamping"}>Values always clamp to the configured axis ranges and snap to `stepX` / `stepY`.</KeyRow>
<KeyRow gesture={"Commit event"}>`onValueCommitted` fires when a gesture that changed the value ends.</KeyRow>
<KeyRow gesture={"Lagging value"}>While dragging, the cursor follows the pointer even if a controlled `value` updates late. Reject a value with `eventDetails.cancel()`.</KeyRow>
</KeyTable>

### Keyboard

On the focused pad:

<KeyTable title="Keys">
<KeyRow gesture={"`ArrowLeft` / `ArrowRight`"}>Decrease / increase X by `stepX`</KeyRow>
<KeyRow gesture={"`ArrowUp` / `ArrowDown`"}>Increase / decrease Y by `stepY`</KeyRow>
<KeyRow gesture={"`Shift` + arrow"}>Move by 10 steps</KeyRow>
<KeyRow gesture={"`PageUp` / `PageDown`"}>Increase / decrease Y by `stepY × 10`</KeyRow>
<KeyRow gesture={"`Home` / `End`"}>X to `minX` / `maxX`</KeyRow>
</KeyTable>

### Wheel

Wheel and trackpad input over the pad moves the point by the scrolled distance: scrolling up raises Y, scrolling right raises X. Reported as `eventDetails.reason === "wheel"`.

## API reference

### Root

Groups all parts of the pad and owns its two-dimensional value. Exposes the value position as CSS variables for crosshairs and guides: `--xy-pad-x` (from the left) and `--xy-pad-y` (from the top), as percentages. Renders a `<div>` element.

<TypeTable>
<TypeRow name={"defaultValue"} type={"Point"}>Uncontrolled starting value. Defaults to the center of the pad.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>
<TypeRow name={"format"} type={"Intl.NumberFormatOptions"}>Formats each axis for `XYPad.Value` and the inputs' `aria-valuetext`.</TypeRow>
<TypeRow name={"locale"} type={"Intl.LocalesArgument"}></TypeRow>
<TypeRow name={"maxX"} type={"number"} default={"100"}></TypeRow>
<TypeRow name={"maxY"} type={"number"} default={"100"}></TypeRow>
<TypeRow name={"minX"} type={"number"} default={"0"}></TypeRow>
<TypeRow name={"minY"} type={"number"} default={"0"}></TypeRow>
<TypeRow name={"onValueChange"} type={"(value: Point, eventDetails: ChangeEventDetails) => void"}>Fires on every change: press, drag, keyboard, wheel and input changes.</TypeRow>
<TypeRow name={"onValueCommitted"} type={"(value: Point, eventDetails: CommitEventDetails) => void"}>Fires when an interaction ends with a new value.</TypeRow>
<TypeRow name={"stepX"} type={"number"} default={"1"}></TypeRow>
<TypeRow name={"name"} type={"string"}>Names the pad for a form: its two inputs submit as `name.x` and `name.y`.</TypeRow>
<TypeRow name={"stepY"} type={"number"} default={"1"}></TypeRow>
<TypeRow name={"value"} type={"Point"}></TypeRow>

<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
<TypeRow name={"data-dragging"}>Whether a pointer is dragging on the pad.</TypeRow>

### Control

The pad surface: a press jumps the value to the pointer and a drag follows it; the mouse wheel / trackpad moves it too. Sets `touch-action: none` so touch drags don't scroll the page. Renders a `<div>` element.

<TypeTable title="Data attributes">
<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
<TypeRow name={"data-dragging"}>Whether a pointer is dragging on the pad.</TypeRow>
</TypeTable>

### Thumb

Marks the value on the pad (`left`/`top` as percentages, centered with `translate`). Holds two native `<input type="range">`s, one per axis: the X input takes focus, both carry the accessible name, and the arrow keys move both axes. Renders a `<div>` element.

<TypeTable>
<TypeRow name={"getAriaLabel"} type={"(axis: Axis) => string"}>Names each axis input. Defaults to `aria-label` followed by "X" / "Y".</TypeRow>
<TypeRow name={"getAriaValueText"} type={"(formattedValue: string, value: number, axis: Axis) => string"}>Returns an axis input's `aria-valuetext`. Defaults to the formatted value.</TypeRow>
</TypeTable>

<TypeTable title="Data attributes">
<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
<TypeRow name={"data-dragging"}>Whether a pointer is dragging on the pad.</TypeRow>
</TypeTable>

### Value

The formatted value (`format`/`locale` on Root), `"x, y"` by default. Renders a `<output>` element.

<TypeTable>
<TypeRow name={"children"} type={"| React.ReactNode | ((formattedX: string, formattedY: string, value: Point) => React.ReactNode)"}></TypeRow>
</TypeTable>

<TypeTable title="Data attributes">
<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
<TypeRow name={"data-dragging"}>Whether a pointer is dragging on the pad.</TypeRow>
</TypeTable>

### Label

Accessible label, associated with both axis inputs. Renders a `<div>` element.

<TypeTable title="Data attributes">
<TypeRow name={"data-disabled"}>Present when disabled.</TypeRow>
<TypeRow name={"data-dragging"}>Whether a pointer is dragging on the pad.</TypeRow>
</TypeTable>

### Registry component

`XYPad` accepts style props (`size`, `formatValue`, `valueDisplay`, `className`) plus primitive props from `XYPadPrimitive.Root.Props`. `aria-label`, `aria-labelledby`, and `aria-describedby` are forwarded to the axis inputs.

`@audio-ui/react/xypad` exposes `XYPad.Root`, `XYPad.Control` (the pad surface), `XYPad.Thumb` (positioned at the value, holds the axis inputs), `XYPad.Value` (formatted `<output>`), and `XYPad.Label`. Every part accepts a `render` prop, `className` / `style` as functions of state, and exposes `data-disabled` / `data-dragging`. Draw grids and crosshairs with your own elements and the `--xy-pad-x` / `--xy-pad-y` variables.
