Repeats the sound. The panel draws the echoes the state makes, one line each, fainter as they fade: drag the handle on the first one across for the time and up for the feedback. It is a device like the [compressor](/docs/components/compressor): a state, a panel that draws it, an engine that plays it and tools an agent calls, each its own file.

## Usage

```tsx
import { DelayPanel } from "@/components/audio-ui/devices/delay/panel";
import { delayDevice } from "@/components/audio-ui/devices/delay/device";

const [state, setState] = useState(() => delayDevice.defaults());

<DelayPanel onValueChange={setState} value={state} />;
```

The state is a plain object keyed by parameter id, so a host stores it, saves it with its project and sends it where it likes. `delayTaps(state, windowMs)` returns the echoes a state makes, which is what the panel draws.

## The engine

```ts
import { createDelayEngine } from "@/components/audio-ui/devices/delay/engine";

const engine = createDelayEngine(ctx, state);
source.connect(engine.input);
engine.output.connect(ctx.destination);
engine.update(nextState); // parameters ramp: no click
engine.dispose();
```

The repeats go round a low-pass tone filter, so each is darker than the one before. A change of time glides slowly, so the echo bends like a tape instead of clicking, and the feedback stops short of 95 % so it cannot run away.

## The tools

```ts
import { deviceTools } from "@audio-ui/core/device";
import { delayDevice } from "@/components/audio-ui/devices/delay/device";

const [set, reset] = deviceTools(delayDevice);
```

`set` and `reset` change the state, with the ranges the device enforces: a value out of range is brought in and reported, a wrong one is refused by name, and a call never throws.

## Accessibility

Every control is a native input: the knobs are sliders named after their parameter, with the value and unit as the text value, the switch is a toggle button, and everything takes the keyboard.
