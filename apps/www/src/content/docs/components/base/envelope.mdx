Envelope for editing a linear ramp (an ADSR shape, an automation curve, any breakpoint-based ramp). The registry component wraps `Envelope` primitives from `@audio-ui/react` and renders an SVG polyline connecting draggable points.

## Overview

- **Value model:** `value: { x: number; y: number }[]`, both axes normalized 0-1 and sorted by `x`. The consumer maps the normalized range to its own domain (time, level, frequency — whatever the ramp represents).
- **Interaction model:** Drag a point to move it — dragging never deletes a point. Double-click empty space to add a point there; double-click an existing point to remove it. A point's `x` is clamped between its neighbors, so points can never cross or reorder mid-drag.
- **Point count:** Dynamic — points are added and removed via interaction, floored at `minPoints` (default `2`, since a ramp needs at least a start and an end).
- **Accessibility:** One roving tab stop; arrow keys nudge the focused point's `x`/`y`, `Delete` or `Backspace` removes it — the same outcome as double-clicking, reachable from the keyboard.

## Usage

```tsx
import { Envelope } from "@/components/audio/envelope";
```

**Uncontrolled** - initial points only:

```tsx
<Envelope
  defaultValue={[
    { x: 0, y: 0 },
    { x: 0.2, y: 1 },
    { x: 0.6, y: 0.5 },
    { x: 1, y: 0 },
  ]}
/>
```

**Controlled** - drive points from state:

```tsx
const [points, setPoints] = useState(initialPoints);

<Envelope
  onValueChange={setPoints}
  onValueCommit={(next) => console.log("Committed:", next)}
  value={points}
/>
```

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Drag a point** | Moves it; `x` clamps between its neighbors, `y` clamps to [0,1]. Never deletes. |
| **Double-click empty space** | Adds a point at that location (disable with `allowAddPoints={false}`). |
| **Double-click a point** | Removes it, unless at `minPoints` (disable with `allowRemovePoints={false}`). |
| **Commit event** | `onValueCommit` fires when a drag ends, or immediately for add/remove. |

### Keyboard

One tab stop for the whole envelope; focus then roves between points:

| Key | Action |
| --- | ------ |
| `ArrowUp` / `ArrowDown` | Nudge the focused point's `y` |
| `ArrowLeft` / `ArrowRight` | Nudge the focused point's `x` (clamped between neighbors) |
| `Delete` / `Backspace` | Remove the focused point, unless at `minPoints` |

## API reference

`Envelope` accepts style props (`size`, `className`) plus primitive props from `EnvelopePrimitive.RootProps`.

### Value and state

| Prop            | Type                          | Default | Description                                                      |
| --------------- | ------------------------------ | ------- | ------------------------------------------------------------------ |
| `value`         | `{ x: number; y: number }[]`  | -       | Controlled points, normalized 0-1, sorted by `x`.                |
| `defaultValue`  | `{ x: number; y: number }[]`  | ADSR-like 4-point shape | Uncontrolled default points.                             |
| `allowAddPoints` | `boolean`                    | `true`  | Whether double-clicking empty space adds a point.                |
| `allowRemovePoints` | `boolean`                 | `true`  | Whether double-clicking (or Delete/Backspace on) a point removes it. |
| `minPoints`     | `number`                       | `2`     | Floor on the number of points; removal is blocked at this count. |
| `disabled`      | `boolean`                      | `false` | Whether the envelope is disabled.                                 |
| `onValueChange` | `(points) => void`             | -       | Callback when points change during interaction.                  |
| `onValueCommit` | `(points) => void`             | -       | Callback when points are committed (on release, add, or remove). |
| `aria-label`    | `string`                       | `"Envelope"` | Accessible name for the envelope.                            |
| `aria-labelledby` | `string`                     | -       | ID of a labeling element.                                         |

### Layout and display

| Prop        | Type                          | Default     | Description                        |
| ----------- | ------------------------------ | ----------- | ----------------------------------- |
| `size`      | `"sm" \| "default" \| "lg"`   | `"default"` | Size variant (sets the envelope height). |
| `className` | `string`                      | -           | Additional CSS classes.            |

Additional valid HTML attributes passed to `Envelope.Root` are forwarded.
