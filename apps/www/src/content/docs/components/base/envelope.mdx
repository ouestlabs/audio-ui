Envelope for editing a linear ramp (an ADSR shape, an automation curve, any breakpoint-based ramp). The registry component wraps `Envelope` primitives from `@audio-ui/react` and renders an SVG polyline connecting draggable points.

## Overview

- **Value model:** `value: { x: number; y: number }[]`, both axes normalized 0-1 and sorted by `x`. The consumer maps the normalized range to its own domain (time, level, frequency — whatever the ramp represents).
- **Interaction model:** Drag a point to move it — dragging never deletes a point. Double-click empty space to add a point there; double-click an existing point to remove it. A point's `x` is clamped between its neighbors, so points can never cross or reorder mid-drag.
- **Point count:** Dynamic — points are added and removed via interaction, between `minPoints` (default `2`, since a ramp needs at least a start and an end) and `maxPoints`. Set both to the same count to fix the shape.
- **Accessibility:** One roving tab stop; arrow keys nudge the focused point's `x`/`y`, `Delete` or `Backspace` removes it — the same outcome as double-clicking, reachable from the keyboard. Each point is a `role="slider"` on its level, named "Point n of N" by the registry component; the primitive leaves naming (`aria-label`) and value text (`getAriaValueText`) to you.

## Usage

```tsx
import { Envelope } from "@/components/audio/envelope";
```

**Uncontrolled** - initial points only:

```tsx
<Envelope
  defaultValue={[
    { x: 0, y: 0 },
    { x: 0.2, y: 1 },
    { x: 0.6, y: 0.5 },
    { x: 1, y: 0 },
  ]}
/>
```

**Controlled** - drive points from state:

```tsx
const [points, setPoints] = useState(initialPoints);

<Envelope
  onValueChange={setPoints}
  onValueCommitted={(next, details) => console.log("Committed:", next, details.reason)}
  value={points}
/>
```

## Interaction

### Pointer

| Behavior | Details |
| -------- | ------- |
| **Drag a point** | Moves it; `x` clamps between its neighbors, `y` clamps to [0,1]. Never deletes. While dragging, the point follows the pointer even if a controlled `value` updates late. |
| **Double-click empty space** | Adds a point at that location, unless at `maxPoints`. |
| **Double-click a point** | Removes it, unless at `minPoints`. |
| **Commit event** | `onValueCommitted` fires when a drag that moved a point ends, or immediately for add/remove. |

A refused add or remove sets `data-blocked` for a moment on the graph or the point, which the registry styles turn into a short shake.

### Keyboard

One tab stop for the whole envelope; focus then roves between points:

| Key | Action |
| --- | ------ |
| `ArrowUp` / `ArrowDown` | Nudge the focused point's `y` by `step` |
| `ArrowLeft` / `ArrowRight` | Nudge the focused point's `x` by `step` (clamped between neighbors) |
| `Shift` + arrow | Nudge by 10 steps |
| `Delete` / `Backspace` | Remove the focused point, unless at `minPoints` |

## API reference

`Envelope` accepts style props (`size`, `className`) plus primitive props from `EnvelopePrimitive.Root.Props`. `aria-label` / `aria-labelledby` name the envelope group.

### Value and state

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `value` | `{ x: number; y: number }[]` | - | Controlled points, normalized 0-1, sorted by `x`. |
| `defaultValue` | `{ x: number; y: number }[]` | ADSR-like 5-point shape | Uncontrolled starting points. |
| `minPoints` | `number` | `2` | Floor on the number of points; removal is blocked at this count. |
| `maxPoints` | `number` | - | Ceiling on the number of points; adding is blocked at this count. |
| `step` | `number` | `0.01` | Keyboard step on both axes, in normalized units. |
| `disabled` | `boolean` | `false` | Whether the envelope is disabled. |
| `format` | `Intl.NumberFormatOptions` | - | Formats point coordinates for each point's value text. |
| `onValueChange` | `(points, eventDetails) => void` | - | Every change. `eventDetails.reason` is `"drag"`, `"keyboard"`, `"add"`, or `"remove"`, and `eventDetails.index` is the affected point; call `eventDetails.cancel()` to reject it. |
| `onValueCommitted` | `(points, eventDetails) => void` | - | When an interaction that changed the points ends (release, key press, add, or remove). |

### Layout and display

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Size variant (sets the envelope height). |
| `className` | `string` | - | Classes for the graph surface. |

### Primitive parts

`@audio-ui/react/envelope` exposes `Envelope.Root`, `Envelope.Graph` (the SVG surface; double-click to add), `Envelope.Line` and `Envelope.Fill` (the curve and the area under it), `Envelope.Points` (renders one child per point) and `Envelope.Point` (the draggable handle). Every part accepts a `render` prop and `className` / `style` as functions of state; points expose `data-dragging`, `data-removable`, `data-blocked`, `data-disabled` and `data-index`.
