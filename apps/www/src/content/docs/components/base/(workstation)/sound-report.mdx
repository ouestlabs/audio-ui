## Usage

`SoundReport` is controlled: it is open while `report` is set, and `onOpenChange(false)` is where you clear it. The report is the one `reportSound` of [`@audio-ui/engine/analysis`](/docs/engine/analysis) gives, held by [`useSoundReport`](/docs/hooks/use-sound-report).

```tsx
import { SoundReport } from "@/components/audio-ui/sound-report";

<SoundReport onOpenChange={(open) => !open && clear()} report={report} />;
```

| Prop | Type | |
| --- | --- | --- |
| `report` | `SoundReport \| null` | What the sound was read as. `null` closes the dialog. |
| `onOpenChange` | `(open: boolean) => void` | The dialog was dismissed. |
