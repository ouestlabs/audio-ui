## Anatomy

It is built on the headless [Sequencer](/docs/react/sequencer) of `@audio-ui/react`: its parts, and how they fit, are on that page.

## Usage

```tsx
import { Sequencer } from "@/components/audio-ui/sequencer";

<Sequencer
  aria-label="Drum pattern"
  onValueChange={setPattern}
  rowLabels={["Kick", "Snare", "Hihat"]}
  source={step}
  value={pattern}
/>;
```

`value` is a row per sound, each a list of steps: `boolean[][]`. `velocities` is how loud each step plays, from 0 to 1, in the same shape; a step it does not list plays at full. Add `showVelocity` for a bar under each row to draw them. `source` is the step being played, a live `{ getSnapshot, subscribe }` such as one made with `createSource`: a clock ticking every step never re-renders React.

## Interaction

<KeyTable title="Gestures">
<KeyRow gesture={"Press a step"}>Flips it.</KeyRow>
<KeyRow gesture={"Drag on"}>Paints the new state across every step the pointer crosses.</KeyRow>
<KeyRow gesture={"Arrow keys, `Home`, `End`"}>Move between steps; with `Ctrl` or `Cmd`, `Home` and `End` go to the corners.</KeyRow>
<KeyRow gesture={"`Space`, `Enter`"}>Flip the focused step.</KeyRow>
<KeyRow gesture={"Press or drag on a velocity bar"}>Sets the velocity where the pointer is, and draws across the steps of the row.</KeyRow>
<KeyRow gesture={"`Alt` + click, `Delete` on a velocity bar"}>Bring the step back to full.</KeyRow>
<KeyRow gesture={"Arrow keys, `Page Up`/`Down`, `Home`/`End` on a velocity bar"}>Change the velocity by 5%, by 25%, or to silent or full.</KeyRow>
</KeyTable>

The steps share one tab stop, and each is a toggle button (`aria-pressed`) named after its row and step.

## API reference

The props of the headless parts are on [Sequencer](/docs/react/sequencer#api-reference).

### Registry component

`Sequencer` takes the `Root` props, plus:

<TypeTable>
<TypeRow name={"rowLabels"} type={"string[]"}>Names written beside each row, and its accessible name.</TypeRow>
<TypeRow name={"beatEvery"} type={"number"} default={"4"}>Highlights every nth step.</TypeRow>
<TypeRow name={"showVelocity"} type={"boolean"} default={"false"}>Draws a bar under each row to set how loud every step plays.</TypeRow>
<TypeRow name={"size"} type={'"default" | "sm"'} default={'"default"'}>`sm` draws short steps and a thin bar under them, so many rows fit.</TypeRow>
<TypeRow name={"shadeByVelocity"} type={"boolean"} default={"false"}>Draws a step that plays fainter the softer it plays, by `velocities`.</TypeRow>
<TypeRow name={"renderCell"} type={"(row: number, step: number) => ReactNode"}>What a step shows inside it, such as how many times it repeats.</TypeRow>
<TypeRow name={"renderRowLabel"} type={"(row: number) => ReactNode"}>What sits beside a row in place of its written name, such as a button that sounds it; the row keeps its name for assistive technology.</TypeRow>
</TypeTable>
