Meter for monitoring audio levels (stereo output, individual channel strips, or any multi-channel source). The registry component wraps `Meter` primitives from `@audio-ui/react` and renders one bar per channel, switching from success to destructive when a channel clips, with an optional peak-hold mark. The primitive is display only — there is no pointer, keyboard, or focus handling, since there is nothing to control.

## Overview

- **Value model:** a dB reading per channel (stereo = `[left, right]`), given either as the `value` prop or as a live [`source`](#feeding-real-levels); the number of readings is the channel count.
- **Peak hold:** An optional peak level per channel positions a peak-hold mark. The primitive has no clock — the [`use-audio-levels`](#feeding-real-levels) hook (or Tone.js, or any other source) computes and decays it.
- **Clipping:** Channels at or above `clipThreshold` (default `0` dB) get a `data-clipping` attribute for styling a clip indicator.
- **Accessibility:** Each channel is a `role="meter"` with `aria-valuenow`/`min`/`max` and a value text in dB ("-6 dB") — a static, query-able value, not an `aria-live` region, so a fast-changing meter doesn't spam screen readers with every update. `aria-label` names the group; with several channels each one is named "… 1", "… 2".

## Usage

```tsx
import { Meter } from "@/components/audio/meter";
```

**Static levels:**

```tsx
<Meter value={[-9, -14]} />
```

**With a peak-hold mark:**

```tsx
<Meter peak={[-4, -8]} value={[-9, -14]} />
```

## Feeding real levels

`value` and `peak` are plain props: fine for static or slowly changing levels, but a signal sampled 60 times a second would re-render React on every frame. For live audio, pass a `source` instead — the meter subscribes to it and writes each frame straight to the DOM, with no React render at all.

The `use-audio-levels` hook (`npx shadcn@latest add @audio/use-audio-levels`) returns such a source. It samples RMS level (in dB) from one `AnalyserNode` per channel every animation frame, with a peak-hold level that holds the loudest recent level for 1.5s before decaying:

```tsx
const levels = useAudioLevels([leftAnalyser, rightAnalyser]);

<Meter aria-label="Stereo output" source={levels} />;
```

A source is any object with the shape of an external store, so you can bring your own (Tone.js, a worklet, a WebSocket):

```ts
interface MeterSource {
  getSnapshot: () => { levels: readonly number[]; peaks?: readonly number[] };
  subscribe: (listener: () => void) => () => void;
}
```

To also read the levels in React (a numeric readout, say), use `useSyncExternalStore(levels.subscribe, levels.getSnapshot)`.

## API reference

`Meter` accepts style props (`size`, `peakMarks`, `className`) plus primitive props from `MeterPrimitive.Root.Props`.

### Value and state

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `value` | `number[]` | - | Level (dB) per channel; array length is the channel count. |
| `peak` | `number[]` | - | Peak-hold level (dB) per channel. Omit to hide peak marks. |
| `source` | `MeterSource` | - | A live signal painted outside React; takes precedence over `value` and `peak`. |
| `min` | `number` | `-60` | Minimum of the dB range. |
| `max` | `number` | `6` | Maximum of the dB range. |
| `clipThreshold` | `number` | `0` | Level (dB) at or above which a channel is marked as clipping. |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Bar direction. |
| `format` | `Intl.NumberFormatOptions` | one decimal | Formats each level for the value text. |
| `aria-label` | `string` | - | Accessible name for the meter group and its channels. |

### Layout and display

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Size variant (sets the meter height). |
| `peakMarks` | `"visible" \| "hidden"` | `"visible"` | Shows or hides the peak-hold mark per channel. |
| `className` | `string` | - | Additional CSS classes. |

### Primitive parts

`@audio-ui/react/meter` exposes `Meter.Root` (the group), `Meter.Channels` (one child per channel), `Meter.Channel` (a `role="meter"`), `Meter.Track`, `Meter.Indicator` (the lit part), `Meter.Peak` (the peak-hold mark), `Meter.Value` (the formatted level) and `Meter.Label`. Channel parts expose `data-orientation` and `data-clipping`.
