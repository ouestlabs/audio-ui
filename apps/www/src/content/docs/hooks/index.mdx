A hook is React's side of a library: it owns a lifecycle (making and disposing engines, listening to an input) or a subscription (a live value), and nothing else. A hook given a node works on that node's audio context; one that starts sound from nothing asks `webAudio` for the page's. Install each with `npx shadcn@latest add @audio-ui/<name>`.
