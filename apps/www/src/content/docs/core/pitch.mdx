## Usage

Pitches are MIDI note numbers, 60 being middle C. A `Scale` is a name of `SCALES` on a root pitch class, 0 being C:

```ts
import { inScale, nearestInScale, pitchName, scalePitchClasses } from "@audio-ui/core/pitch";

const aMinor = { name: "minor", root: 9 };

pitchName(60); // "C4"
scalePitchClasses(aMinor); // [0, 2, 4, 5, 7, 9, 11]
inScale(61, aMinor); // false: C# is not in A minor
nearestInScale(61, aMinor); // 60: of two as near, the lower
```

`SCALES` holds the steps of each scale as semitones above its root: `chromatic`, the major and minor scales (natural, harmonic, melodic), the two pentatonics, the blues, the whole-tone scale and the modes (dorian, phrygian, lydian, mixolydian, locrian). A piano roll that keeps notes in a key snaps a dragged pitch with `nearestInScale`, and shades the rows `inScale` leaves out.

`pitchName` follows the convention tuners and score editors share, middle C as C4; `pitchClassName` drops the octave, and `isBlackKey` says which keys a keyboard draws black.
