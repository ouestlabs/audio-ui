`@audio-ui/engine` holds what makes and times the sound: a device as named parameters and the tools an agent drives it with, musical time and the look-ahead scheduler a transport runs on, levels and the curves a panel draws, the page's MIDI input, named scales, and the clip player that plays an arrangement in an `AudioWorklet`. It runs on the main thread, in a worker or in a worklet, under any framework or none.

It is one package, `npm install @audio-ui/engine`, and each module is its own entry point, so a page pays only for what it imports. It builds on [`@audio-ui/core`](/docs/core), the logic of the controls, and on [audio.js](https://audio.js.org) where an atom does the job.

## Modules

| Module | What it holds |
| --- | --- |
| [`device`](/docs/engine/device) | A device as a description: `defineDevice`, its state, `apply` with what each change did, the bindings an engine implements, and the tools an agent drives it with. |
| [`time`](/docs/engine/time) | Musical time: tempos and signatures, bars and beats, grid divisions, tempo-synced note values, warp markers, the metronome, and the look-ahead scheduler a transport clock runs on. |
| [`analysis`](/docs/engine/analysis) | Reading a signal: levels in dB, a log-axis spectrum and its peaks, the curves of a filter, an equalizer and a compressor, waveform peaks, transients and auto-warp. |
| [`pitch`](/docs/engine/pitch) | Named scales: the pitch classes each keeps, the nearest pitch in one, and a scale as a piano roll reads it. |
| [`midi`](/docs/engine/midi) | MIDI input as a source of notes, a raw message read, pitch bend in semitones. |
| [`playback`](/docs/engine/playback) | What plays when: clips placed in frames, the transport on the audio clock, the clip player's processor, streamed recordings, and the mixer's pan law, solo and delay compensation. |
