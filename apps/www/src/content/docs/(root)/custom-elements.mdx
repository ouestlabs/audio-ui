`@audio-ui/elements` provides every primitive as a set of unstyled, accessible custom elements. Each one is built on `@audio-ui/core` and keeps API parity with [`@audio-ui/react`](/docs/primitives): the same parts, keyboard interactions, ARIA semantics and `data-*` state attributes. The elements work in plain HTML and in any framework that renders HTML, such as Vue, Svelte, Angular or Lit. Every primitive in the [API reference](#api-reference) has a live preview.

## Installation

```bash
npm install @audio-ui/elements
```

Each primitive is a separate entry point, `@audio-ui/elements/<primitive>`, which registers its elements when imported. The package root registers every primitive. Import an entry once, before the elements are used:

```js
import "@audio-ui/elements/knob";
```

Registration is a no-op on the server: server-rendered markup upgrades once the module loads in the browser.

## Value and events

Every control follows the same contract:

| Member | Kind | Description |
| --- | --- | --- |
| `input` | Event | Fires on every change. `event.detail` holds the new `value` and the `reason` for the change, such as `"drag"`, `"keyboard"`, `"wheel"`, `"reset"` or `"input-change"`. Calling `preventDefault()` rejects the change. |
| `change` | Event | Fires once when an interaction that changed the value ends. Use it to commit: start a note, record an undo step, save. |
| `value` | Property | Reads the current value, and sets it. Framework bindings (`:value` in Vue, `value={}` in Svelte) write this property. During a drag, the control follows the pointer even when the bound value lags behind. |
| `name` | Attribute | Submits the value with the enclosing form, through the control's native range input. |

A part that holds a value of its own fires events prefixed with its name, for example `clipinput` and `clipchange` on a timeline clip. These never collide with the control's own `input` and `change`, and they bubble, so a single listener on the root can handle every part.

## Styling

The elements apply only the styles their behavior depends on: the display of each box, the positioning of placed parts, `touch-action` on interactive surfaces. These rules are wrapped in `:where()`, so they carry no specificity and any rule of yours takes precedence. No color, size or spacing is set. Style the parts by tag and by the same state attributes as the React parts:

```css
audio-ui-knob-control { width: 4rem; height: 4rem; cursor: grab; }
audio-ui-knob[data-dragging] audio-ui-knob-control { cursor: grabbing; }
audio-ui-knob-track, audio-ui-knob-indicator { position: absolute; inset: 0; }
audio-ui-knob-track { color: var(--muted); }
audio-ui-knob-indicator { color: var(--primary); }
audio-ui-knob-thumb:has(input:focus-visible) { outline: 2px solid var(--ring); }
```

Parts drawn as SVG use `currentColor`. Classes work as well: the knob and fader previews apply the registry's Tailwind classes.

### Sequencer

`<audio-ui-sequencer>` is a step grid with one row per sound and `role="group"`. Pressing a cell toggles it, and dragging applies the new state to every cell crossed. The cells share one tab stop and are navigated with the arrow keys. Rows and steps are generated from templates:

<ElementsPreview name="sequencer" />

```html
<audio-ui-sequencer aria-label="Pattern" default-value="x...x... ..x...x.">
  <audio-ui-sequencer-rows labels="Kick, Snare">
    <template>
      <audio-ui-sequencer-steps>
        <template><audio-ui-sequencer-cell></audio-ui-sequencer-cell></template>
      </audio-ui-sequencer-steps>
    </template>
  </audio-ui-sequencer-rows>
</audio-ui-sequencer>
```

<TypeTable>
<TypeRow name={"value"} type={"string"}>The pattern as text: one word per row, one character per step, `x` for on and `.` for off. The `value` property reads and sets it as `boolean[][]`.</TypeRow>
<TypeRow name={"default-value"} type={"string"}>The initial pattern, in the same notation.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>
</TypeTable>

| Event | Detail | Description |
| --- | --- | --- |
| `input`, `change` | `{ value, reason }` | The pattern changes, then the gesture ends |
| `velocityinput`, `velocitychange` | `{ velocities, reason }` | Step velocities change, then the gesture ends |

The `velocities` property holds each step's velocity as `number[][]` (0 to 1). The `source` property, `{ getSnapshot, subscribe }` returning the current step, marks that step's cells with `data-current`.

| Part | Description |
| --- | --- |
| `<audio-ui-sequencer-rows>` | Generates an `<audio-ui-sequencer-row>` per row from its `<template>`. `labels` names them, separated by commas |
| `<audio-ui-sequencer-row>` | A row with `role="group"`, for its `index` |
| `<audio-ui-sequencer-steps>` | Generates an `<audio-ui-sequencer-step>` per step from its `<template>`. Both render with `display: contents`, so the cells are the grid items |
| `<audio-ui-sequencer-cell>` | A step, a toggle button pressed when on (`data-on`), labelled with its row and step ("Kick, step 5") |
| `<audio-ui-sequencer-velocity>` | A step's velocity as a bar sized by `--sequencer-velocity`. Press or drag to set it; Alt + click or Delete resets it to full; its native range input takes the keyboard |

### Envelope

`<audio-ui-envelope>` is a breakpoint envelope editor with `role="group"`. Points are dragged to move, added with a double click on the graph, and removed with a double click, Alt + click or Delete. Each segment has a curve handle at its midpoint, and Alt + drag on the graph bends the segment under the pointer. The points share one tab stop: Page Up and Page Down (or Home and End) move between them, and the arrow keys move the focused point. Points and segment handles are generated, from a `<template>` when one is provided:

<ElementsPreview name="envelope" />

```html
<audio-ui-envelope aria-label="Amp envelope" default-value="0 0, 0.2 1, 0.6 0.5, 1 0">
  <audio-ui-envelope-graph>
    <audio-ui-envelope-fill></audio-ui-envelope-fill>
    <audio-ui-envelope-line></audio-ui-envelope-line>
  </audio-ui-envelope-graph>
  <audio-ui-envelope-segments></audio-ui-envelope-segments>
  <audio-ui-envelope-points></audio-ui-envelope-points>
</audio-ui-envelope>
```

<TypeTable>
<TypeRow name={"value"} type={"string"}>The points, separated by commas, each `x y` or `x y curve`: coordinates from 0 to 1, curve from -1 to 1. The `value` property reads and sets them as `{ x, y, curve? }[]`.</TypeRow>
<TypeRow name={"default-value"} type={"string"}>The initial points, in the same notation. Defaults to an ADSR shape.</TypeRow>
<TypeRow name={"min-points"} type={"number"} default={"2"}>Removal is refused at this count.</TypeRow>
<TypeRow name={"max-points"} type={"number"}>Adding is refused at this count.</TypeRow>
<TypeRow name={"snap"} type={"string"} default={"0"}>Pointer grid: one step, such as `0.25`, or `"x y"` per axis (`"0.125 0"` snaps time only). Cmd or Ctrl bypasses it.</TypeRow>
<TypeRow name={"step"} type={"number"} default={"0.01"}>Keyboard step on both axes.</TypeRow>
<TypeRow name={"format"} type={"string"}>`Intl.NumberFormat` options as JSON, for point coordinates.</TypeRow>
<TypeRow name={"locale"} type={"string"}>Defaults to the browser locale.</TypeRow>

`input` and `change` carry `{ value, reason, index }`, with `reason` one of `drag`, `keyboard`, `add`, `remove` or `curve`. The `getPointValueText(point, index)` and `getCurveValueText(curve, index)` properties customize `aria-valuetext`.

| Part | Description |
| --- | --- |
| `<audio-ui-envelope-graph>` | The drawing surface, filling the envelope. A double click adds a point; carries `data-blocked` briefly when adding is refused |
| `<audio-ui-envelope-line>` | The curve through the points, in `currentColor`, with a constant stroke width set by `stroke-width` |
| `<audio-ui-envelope-fill>` | The area under the curve, in `currentColor` |
| `<audio-ui-envelope-points>` | Generates an `<audio-ui-envelope-point>` per point. `label` names them, with `{n}` and `{count}` placeholders (`Point {n} of {count}` by default) |
| `<audio-ui-envelope-point>` | A slider on the point's level, positioned with `left` and `bottom`. Carries `data-dragging`, `data-removable`, and `data-blocked` briefly when removal is refused |
| `<audio-ui-envelope-segments>` | Generates an `<audio-ui-envelope-segment>` per segment. `label` names them (`Curve {n}` by default) |
| `<audio-ui-envelope-segment>` | A slider on the segment's curve, from -1 to 1, at its midpoint. Drag or Up and Down to bend; double click or Delete to straighten. Carries `data-flat` when the segment cannot bend |

### Plot

`<audio-ui-plot>` defines two axes and lays out everything drawn on them in axis units, for response curves, filter displays and transfer functions. ### Waveform

`<audio-ui-waveform>` displays audio and, with a control part, seeks through it: a press seeks to the pointer, a drag scrubs, and the keyboard steps. The shape comes from the `peaks` property or a live `levels` source; the position from `value` or a live `source`, exposed as `--waveform-position`:

<ElementsPreview name="waveform" />

```html
<audio-ui-waveform duration="102">
  <audio-ui-waveform-control aria-label="Seek">
    <audio-ui-waveform-canvas></audio-ui-waveform-canvas>
    <audio-ui-waveform-playhead></audio-ui-waveform-playhead>
  </audio-ui-waveform-control>
</audio-ui-waveform>
<script type="module">
  document.querySelector("audio-ui-waveform").peaks = peaks;
</script>
```

<TypeTable>
<TypeRow name={"duration"} type={"number"} default={"1"}>Length of the audio, in the unit of the position, typically seconds.</TypeRow>
<TypeRow name={"value"} type={"number"}>The playback position, from 0 to `duration`.</TypeRow>
<TypeRow name={"default-value"} type={"number"} default={"0"}></TypeRow>
<TypeRow name={"step"} type={"number"}>Arrow key step. Defaults to `duration / 100`.</TypeRow>
<TypeRow name={"large-step"} type={"number"}>Page Up, Page Down and Shift + Arrow step. Defaults to `duration / 10`.</TypeRow>
<TypeRow name={"range"} type={"string"}>The visible window, `"start end"`, for clips and zoomed views. Defaults to the whole audio. Sets `data-outside` while the position is outside it.</TypeRow>
<TypeRow name={"loading"} type={"boolean"}>Seeking is disabled and the bars animate until the audio is available.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>
</TypeTable>

`input` and `change` carry `{ value, reason }`. The root carries `data-active` while a live signal is audible.

| Part | Description |
| --- | --- |
| `<audio-ui-waveform-control>` | The seekable surface, containing the native range input. `getAriaValueText(value, duration)` customizes its announcement. With `selectable`, Shift + drag selects a range and fires `selectioninput` and `selectioncommit` with `[start, end]` |

| `<audio-ui-waveform-region-handle>` | Resizes the region's `edge` (`start` or `end`) by drag or through its native range input |

### Timeline

`<audio-ui-timeline>` is the root of an arrangement: a ruler that sets the position, lanes of clips that move, trim and fade, loop ranges, and a viewport that scrolls and zooms. Units are arbitrary: seconds, beats or steps.

<ElementsPreview name="timeline" />

```html
<audio-ui-timeline duration="32" snap-step="1">
  <audio-ui-timeline-viewport>
    <audio-ui-timeline-ruler aria-label="Position"></audio-ui-timeline-ruler>
    <audio-ui-timeline-track>
      <audio-ui-timeline-track-header>Drums</audio-ui-timeline-track-header>
      <audio-ui-timeline-lane seekable>
        <audio-ui-timeline-clip aria-label="Beat" start="4" length="8">
          <audio-ui-timeline-clip-header>Beat</audio-ui-timeline-clip-header>
        </audio-ui-timeline-clip>
        <audio-ui-timeline-playhead></audio-ui-timeline-playhead>
      </audio-ui-timeline-lane>
    </audio-ui-timeline-track>
  </audio-ui-timeline-viewport>
</audio-ui-timeline>
```

<TypeTable>
<TypeRow name={"duration"} type={"number"} default={"1"}>Length of the timeline, in its units.</TypeRow>
<TypeRow name={"position"} type={"number"}>The playback position. The `source` property follows a live position instead.</TypeRow>
<TypeRow name={"default-position"} type={"number"} default={"0"}></TypeRow>
<TypeRow name={"zoom"} type={"number"}>Pixels per unit. When unset, the timeline fits its width.</TypeRow>
<TypeRow name={"default-zoom"} type={"number"}></TypeRow>
<TypeRow name={"min-zoom"} type={"number"} default={"0"}></TypeRow>
<TypeRow name={"max-zoom"} type={"number"}></TypeRow>
<TypeRow name={"snap-step"} type={"number"} default={"0"}>Grid spacing. Gestures snap to it unless Cmd or Ctrl is held; 0 disables the grid.</TypeRow>
<TypeRow name={"snap-offset"} type={"number"} default={"0"}>Where the grid starts.</TypeRow>
<TypeRow name={"snap-points"} type={"string"}>Magnetic positions for dragged clips and ranges, separated by spaces, such as clip edges and locators.</TypeRow>
<TypeRow name={"step"} type={"number"}>Arrow key step. Defaults to `snap-step`, or `duration / 100`.</TypeRow>
<TypeRow name={"large-step"} type={"number"}>Page Up and Page Down step. Defaults to ten steps.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>

| Event | Detail | Description |
| --- | --- | --- |
| `input`, `change` | `{ value, reason }` | The position changes, then the gesture ends |
| `zoomchange` | `{ value, reason }` | The zoom changes, already clamped. `preventDefault()` rejects it |

Every lane sets `--timeline-unit`, the width of one unit; placed parts set `--timeline-offset` and `--timeline-length`.

| Part | Description |
| --- | --- |

| `<audio-ui-timeline-playhead>` | A marker at the position |

### Piano roll

`<audio-ui-piano-roll>` is a note editor placed inside an `<audio-ui-timeline>`, which provides its length, zoom, grid and position. Its entry point also registers the timeline and piano elements. Notes are set through the `value` property as `{ id, pitch, start, length, velocity?, chance?, muted? }[]`, and the selection through the `selection` property. Rows, notes and velocity bars are generated from them:

<ElementsPreview name="piano-roll" />

```html
<audio-ui-timeline duration="16" snap-step="0.25">
  <audio-ui-piano-roll mode="draw">
    <audio-ui-piano-roll-keys>
      <audio-ui-piano aria-label="Keys"><audio-ui-piano-keys></audio-ui-piano-keys></audio-ui-piano>
    </audio-ui-piano-roll-keys>
    <audio-ui-timeline-viewport>
      <audio-ui-piano-roll-grid aria-label="Notes">
        <audio-ui-piano-roll-rows></audio-ui-piano-roll-rows>
        <audio-ui-piano-roll-notes></audio-ui-piano-roll-notes>
        <audio-ui-timeline-playhead></audio-ui-timeline-playhead>
      </audio-ui-piano-roll-grid>
    </audio-ui-timeline-viewport>
  </audio-ui-piano-roll>
</audio-ui-timeline>
```

<TypeRow name={"max-pitch"} type={"number"} default={"72"}>Highest row.</TypeRow>
