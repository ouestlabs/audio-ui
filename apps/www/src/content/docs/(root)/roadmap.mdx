**audio/ui** is a toolkit for building audio interfaces in React: headless primitives on npm (`@audio-ui/react`) and styled components for [shadcn/ui](https://ui.shadcn.com/) that you copy, paste and customize.

## Current Status

Available today:

### Components

- **Controls**: Knob, Fader, XY Pad and Envelope, with scales, rulers and fine drag
- **Metering and visualization**: Meter and Waveform, from peaks, a live signal or a range of the audio
- **Time**: Timeline, a zoomable ruler with lanes, ranges and a navigator; Piano, Piano Roll, Sequencer, Transport and Scrubber
- **Plot**: Curves and draggable points, for equalizers, filters and compressors

### Blocks

- **Pre-assembled patterns**: a piano roll, a pocket synth, a wave shaper and a waveform player. Browse the [component catalog](/components)

### For agents

- **[MCP server](/docs/mcp)**: list components, read their docs and search the catalog from your agent
- **[Agent skill](/docs/agents)**: teaches your agent which layer to pick and how to wire each component

## What's Next

- **More Audio Components**: Additional audio-specific UI patterns and controls
- **Visualization Components**: Waveform displays, spectrum analyzers, and other audio visualizations
