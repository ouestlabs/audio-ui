MCP is an open protocol that lets AI agents use tools. The audio/ui MCP server gives your agent live access to every component, so it reads the real docs instead of guessing.

The server is remote, needs no account and no install:

```
https://audio-ui.dev/mcp
```

## Connect your client

<TabsContent value="claude">

```bash
claude mcp add --transport http audio-ui https://audio-ui.dev/mcp
```

</TabsContent>

<TabsContent value="cursor">

Add this to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "audio-ui": {
      "url": "https://audio-ui.dev/mcp"
    }
  }
}
```

</TabsContent>

<TabsContent value="vscode">

Add this to `.vscode/mcp.json`:

```json
{
  "servers": {
    "audio-ui": {
      "type": "http",
      "url": "https://audio-ui.dev/mcp"
    }
  }
}
```

</TabsContent>

<TabsContent value="other">

Any client that supports remote servers over Streamable HTTP works. Add a server of type `http` with the URL above.

</TabsContent>

</Tabs>

## Tools

<TypeTable title="Tools">

<TypeRow name="search_catalog">Find ready-made blocks by words like `synth`.</TypeRow>
</TypeTable>

## Usage

Ask your agent in plain words:

- Build a synth control panel with Knob, XY Pad and Fader.
- Add an equalizer with a Plot and draggable band handles.
- Make a piano roll with a keyboard, a velocity lane and a loop range.

## With shadcn

Because audio/ui is also a shadcn registry, the shadcn MCP server can install components too. Run `npx shadcn@latest mcp init` and add the `@audio` registry from the [Registry guide](/docs/registry).

For the best results, also install the [agent skill](/docs/agents).
