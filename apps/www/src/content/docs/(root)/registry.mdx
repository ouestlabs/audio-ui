title: Registry
description: Learn how to use the audio/ui Registry with shadcn/ui.
---

The audio/ui registry adds audio components and blocks to a shadcn/ui project. Add the namespace once, then install any item by name.

## Setup the audio/ui Registry

Add the audio/ui registry namespace to your `components.json`. See the [shadcn registry docs](https://ui.shadcn.com/docs/registry) for the registry config.

```json
{
  "registries": {
    "@audio-ui": "https://www.audio-ui.dev/r/{style}/{name}.json"
  }
}
```

## Usage

Install blocks via the shadcn CLI using the `@audio-ui/{name}` syntax.

```bash
npx shadcn@latest add @audio-ui/block-pocket-synth
```

Install components via the shadcn CLI using the `@audio-ui/{name}` syntax.

```bash
npx shadcn@latest add @audio-ui/knob
```
