This guide walks you through the essential steps to add audio/ui to your shadcn project. If you do not use shadcn/ui, install the headless primitives with `npm install @audio-ui/react` instead, see the [Introduction](/docs).

## Prerequisites

audio/ui is built on **React 19** and [Tailwind CSS v4](https://tailwindcss.com). Ensure your project is set up with these technologies before proceeding. We recommend following the [Official shadcn/ui Installation Guide](https://ui.shadcn.com/docs/installation) to prepare your environment.

## Setup the audio/ui Registry

Add the audio/ui registry namespace to your `components.json` and set your component library and style. See the [shadcn registry docs](https://ui.shadcn.com/docs/registry) for the registry config.

```json
{
  "registries": {
    "@audio": "https://audio-ui.dev/r/{style}/{name}.json"
  }
}
```

## Components

You can install audio/ui using the [**shadcn CLI**](https://ui.shadcn.com/docs/cli) for automation or by manual installation for full control. Both methods apply to everything in [Docs](/docs/) and the [component catalog](/components), including the `block-*` blocks and demos you install with `@audio/…`.

## Styling

Components are styled with a design token system defined by CSS variables and implemented with Tailwind CSS, following the same conventions as shadcn/ui so they're fully customizable. See the [Styling guide](/docs/styling) for details.

## Work with an AI agent

audio/ui is designed to be used by AI coding agents.

- **[Agent skill](/docs/agents):** `npx skills add ouestlabs/audio-ui` teaches your agent which layer to pick and how to install and wire each component.
- **[MCP server](/docs/mcp):** connect `https://audio-ui.dev/mcp` so your agent can list components, read their docs and search the catalog.
- **[llms.txt](/llms.txt):** a structured map of the documentation. Every docs page is also served as markdown.
- **Copy Markdown:** every page has a button to feed its content to your agent.
