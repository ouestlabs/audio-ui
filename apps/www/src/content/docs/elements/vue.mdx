## Setup

Vue resolves an unknown tag as one of its components unless it is told the tag is a custom element. Declare the tags in `vite.config.ts`:

```ts
vue({
  template: {
    compilerOptions: { isCustomElement: (tag) => tag.startsWith("audio-ui-") },
  },
});
```

Then register the elements the app uses, once, as in any page:

```ts
import "@audio-ui/elements/knob";
```

## Types

`@audio-ui/elements/vue` adds every element to Vue's `GlobalComponents`. Import it once, in a file the project's `tsconfig.json` includes:

```ts
import type {} from "@audio-ui/elements/vue";
```

Templates are then checked as for a component: an element's attributes (`min`, `drag-mode`), the properties it has a setter for (`value`, `format`) and its own events, with the type of their `detail`, such as a knob's `input` or a clip's `clipinput`. Strict templates (`vueCompilerOptions.strictTemplates`) are supported. The import adds nothing to the bundle.

## Binding

`v-model` binds an element's `value`: Vue reads it on every `input` and writes it when the model changes.

```vue
<script setup lang="ts">
import "@audio-ui/elements/knob";
import { ref } from "vue";

const cutoff = ref(1000);
</script>

<template>
  <audio-ui-knob min="20" max="20000" scale="log" v-model="cutoff">
    <audio-ui-knob-label>Cutoff</audio-ui-knob-label>
    <audio-ui-knob-control>
      <audio-ui-knob-track />
      <audio-ui-knob-indicator />
      <audio-ui-knob-thumb />
    </audio-ui-knob-control>
    <audio-ui-knob-value />
  </audio-ui-knob>
</template>
```

The knob, the fader, the XY pad, the envelope, the sequencer, the waveform, the piano roll and a plot's handles take `v-model`. `v-model` keeps every value the element proposes. To refuse one, bind `:value` and listen to `@input`, which can call `preventDefault()`:

```vue
<script setup lang="ts">
import type { KnobInputEvent } from "@audio-ui/elements/knob";
import { ref } from "vue";

const cutoff = ref(1000);
const limit = ref(8000);

function onInput(event: KnobInputEvent) {
  if (event.detail.value > limit.value) {
    event.preventDefault();
  } else {
    cutoff.value = event.detail.value;
  }
}
</script>

<template>
  <audio-ui-knob :value="cutoff" @input="onInput" />
</template>
```

A part with a value of its own, such as a timeline clip or a range, fires events prefixed with its name: bind it with `:value` and `@clipinput` or `@rangeinput`.
