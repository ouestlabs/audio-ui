`<audio-ui-xypad>` controls a two-dimensional value `{ x, y }`. A press moves the point to the pointer and a drag follows it; the wheel, the trackpad and the arrow keys move it; a double click or Delete resets it. The position is exposed as `--xy-pad-x` (from the left) and `--xy-pad-y` (from the top), as percentages.

`input` and `change` carry `{ value: { x, y }, reason }`.

| Part | Description |
| --- | --- |
| `<audio-ui-xypad-control>` | The interactive surface: press, drag, wheel, double click to reset |
| `<audio-ui-xypad-thumb>` | Marks the point and contains one native range input per axis. Its `aria-label` labels both axes ("Filter X", "Filter Y"); `label-x` and `label-y` label each one |
| `<audio-ui-xypad-value>` | Both axes, formatted as `"x, y"` |
| `<audio-ui-xypad-label>` | Labels both inputs when the thumb has no accessible name |
