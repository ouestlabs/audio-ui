title: Sequencer
description: "The <audio-ui-sequencer> custom element of @audio-ui/elements: its attributes, its parts and a live preview."
---

`<audio-ui-sequencer>` is a step grid with one row per sound and `role="group"`. Pressing a cell toggles it, and dragging applies the new state to every cell crossed. The cells share one tab stop and are navigated with the arrow keys. Rows and steps are generated from templates:

In plain HTML, a row of `<template>` gives the rows and their steps from labels:

```html
<audio-ui-sequencer aria-label="Pattern" default-value="x...x... ..x...x.">
  <audio-ui-sequencer-rows labels="Kick, Snare">
    <template>
      <audio-ui-sequencer-steps>
        <template><audio-ui-sequencer-cell></audio-ui-sequencer-cell></template>
      </audio-ui-sequencer-steps>
    </template>
  </audio-ui-sequencer-rows>
</audio-ui-sequencer>
```

## API reference

<Module from="@audio-ui/elements/sequencer" />

<TypeTable>
<TypeRow name={"value"} type={"string"}>The pattern as text: one word per row, one character per step, `x` for on and `.` for off. The `value` property reads and sets it as `boolean[][]`.</TypeRow>
<TypeRow name={"default-value"} type={"string"}>The initial pattern, in the same notation.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>
</TypeTable>

| Event | Detail | Description |
| --- | --- | --- |
| `input`, `change` | `{ value, reason }` | The pattern changes, then the gesture ends |
| `velocityinput`, `velocitychange` | `{ velocities, reason }` | Step velocities change, then the gesture ends |

The `velocities` property holds each step's velocity as `number[][]` (0 to 1). The `source` property, `{ getSnapshot, subscribe }` returning the current step, marks that step's cells with `data-current`.

| Part | Description |
| --- | --- |
| `<audio-ui-sequencer-rows>` | Generates an `<audio-ui-sequencer-row>` per row from its `<template>`. `labels` names them, separated by commas |
| `<audio-ui-sequencer-row>` | A row with `role="group"`, for its `index` |
| `<audio-ui-sequencer-steps>` | Generates an `<audio-ui-sequencer-step>` per step from its `<template>`. Both render with `display: contents`, so the cells are the grid items |
| `<audio-ui-sequencer-cell>` | A step, a toggle button pressed when on (`data-on`), labelled with its row and step ("Kick, step 5") |
| `<audio-ui-sequencer-velocity>` | A step's velocity as a bar sized by `--sequencer-velocity`. Press or drag to set it; Alt + click or Delete resets it to full; its native range input takes the keyboard |
