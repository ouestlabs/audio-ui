`<audio-ui-envelope>` is a breakpoint envelope editor with `role="group"`. Points are dragged to move, added with a double click on the graph, and removed with a double click, Alt + click or Delete. Each segment has a curve handle at its midpoint, and Alt + drag on the graph bends the segment under the pointer. The points share one tab stop: Page Up and Page Down (or Home and End) move between them, and the arrow keys move the focused point. ## API reference

<Module from="@audio-ui/elements/envelope" />

<TypeTable>
<TypeRow name={"value"} type={"string"}>The points, separated by commas, each `x y` or `x y curve`: coordinates from 0 to 1, curve from -1 to 1. The `value` property reads and sets them as `{ x, y, curve? }[]`.</TypeRow>
<TypeRow name={"default-value"} type={"string"}>The initial points, in the same notation. Defaults to an ADSR shape.</TypeRow>
<TypeRow name={"min-points"} type={"number"} default={"2"}>Removal is refused at this count.</TypeRow>
<TypeRow name={"max-points"} type={"number"}>Adding is refused at this count.</TypeRow>
<TypeRow name={"snap"} type={"string"} default={"0"}>Pointer grid: one step, such as `0.25`, or `"x y"` per axis (`"0.125 0"` snaps time only). Cmd or Ctrl bypasses it.</TypeRow>
<TypeRow name={"step"} type={"number"} default={"0.01"}>Keyboard step on both axes.</TypeRow>
<TypeRow name={"format"} type={"string"}>`Intl.NumberFormat` options as JSON, for point coordinates.</TypeRow>
<TypeRow name={"locale"} type={"string"}>Defaults to the browser locale.</TypeRow>
<TypeRow name={"disabled"} type={"boolean"}></TypeRow>
</TypeTable>

`input` and `change` carry `{ value, reason, index }`, with `reason` one of `drag`, `keyboard`, `add`, `remove` or `curve`. The `getPointValueText(point, index)` and `getCurveValueText(curve, index)` properties customize `aria-valuetext`.

| Part | Description |
| --- | --- |
| `<audio-ui-envelope-graph>` | The drawing surface, filling the envelope. A double click adds a point; carries `data-blocked` briefly when adding is refused |
| `<audio-ui-envelope-line>` | The curve through the points, in `currentColor`, with a constant stroke width set by `stroke-width` |
| `<audio-ui-envelope-fill>` | The area under the curve, in `currentColor` |
| `<audio-ui-envelope-points>` | Generates an `<audio-ui-envelope-point>` per point. `label` names them, with `{n}` and `{count}` placeholders (`Point {n} of {count}` by default) |
| `<audio-ui-envelope-point>` | A slider on the point's level, positioned with `left` and `bottom`. Carries `data-dragging`, `data-removable`, and `data-blocked` briefly when removal is refused |
| `<audio-ui-envelope-segments>` | Generates an `<audio-ui-envelope-segment>` per segment. `label` names them (`Curve {n}` by default) |
| `<audio-ui-envelope-segment>` | A slider on the segment's curve, from -1 to 1, at its midpoint. Drag or Up and Down to bend; double click or Delete to straighten. Carries `data-flat` when the segment cannot bend |
