The audio/ui registry puts the code of audio components in your project, and you own it. Every item installs by name, with the shadcn CLI of your framework.

<TabsContent value="react">

`@audio-ui` is in shadcn's registry directory, so there is nothing to configure: you need a shadcn/ui project, React 19 and Tailwind CSS v4.

Install blocks via the shadcn CLI using the `@audio-ui/{name}` syntax.

```bash
npx shadcn@latest add @audio-ui/block-pocket-synth
```

Install components via the shadcn CLI using the `@audio-ui/{name}` syntax.

```bash
npx shadcn@latest add @audio-ui/knob
```

The headless primitive alone is `@audio-ui/{name}-react`.

</TabsContent>

<TabsContent value="vue">

The shadcn CLI is for React. Copy a primitive by hand: open the address of its item, `<name>-vue.json` (for the knob, `https://www.audio-ui.dev/r/styles/base-nova/knob-vue.json`), write each entry of `files` to its path under `components/audio-ui/` with its `content`, and install the packages its `dependencies` lists.

</TabsContent>

<TabsContent value="svelte">

The shadcn CLI is for React. Copy a primitive by hand: open the address of its item, `<name>-svelte.json` (for the knob, `https://www.audio-ui.dev/r/styles/base-nova/knob-svelte.json`), write each entry of `files` to its path under `src/lib/components/audio-ui/` with its `content`, and install the packages its `dependencies` lists.

</TabsContent>

<TabsContent value="web">

The shadcn CLI is for React. Copy a primitive by hand: open the address of its item, `<name>-web.json` (for the knob, `https://www.audio-ui.dev/r/styles/base-nova/knob-web.json`), write each entry of `files` to its path under `components/audio-ui/` with its `content`, and install the packages its `dependencies` lists. Import the file once, and it registers the tags.
