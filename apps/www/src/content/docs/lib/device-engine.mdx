## Usage

What a device's engine is, and the pieces an engine is made of, each the one place its behavior lives.

### Engine contracts

Every `create<Name>Engine` is an `EngineFactory`: a context, the state to start from and the host's context (its tempo) in, an engine out. An effect's engine is an `EffectEngine<State>` (an `input`, an `output`, `update`, `dispose`, and `ready`, `sidechain` or `readings` where it has them); an instrument's is an `InstrumentEngine<State, Note>`, with `noteOn` and `noteOff` and no input. Both are the core's bindings with the nodes to connect, so a host that keeps its own engine implements the same `update` and `dispose`.

### createWorkletStage

A worklet that takes over from the clean sound once it loads, with a fade, and builds nothing once the engine is disposed.

```ts
import { createWorkletStage } from "@/lib/device-engine";

const input = ctx.createGain();
const output = ctx.createGain();
let latest = initial;
const stage = createWorkletStage(ctx, {
  input,
  make: () => new AudioWorkletNode(ctx, "my-processor", { parameterData: settingsOf(latest) }),
  ramp: 0.02,
  source: MY_PROCESSOR_SOURCE,
});
stage.connect(output);
// update: stage.node?.parameters.get("drive")?.setTargetAtTime(...); dispose: stage.dispose()
```

### createFeed

Keeps a worklet fed only while the path it plays is heard: connected at once on `set(true)`, taken away 120 ms after `set(false)`, once the path has faded, unless wanted again before.

```ts
import { createFeed } from "@/lib/device-engine";

const feed = createFeed([
  [input, model, 0, 0],
  [sidechain, model, 0, 1], // a key on the worklet's second input
]);
feed.set(wet > 0); // on every update
feed.dispose(); // in the engine's dispose
```

### noiseBuffer

Two seconds of noise from `@audio/synth-noise`, made once per color and context and shared by everything that plays it: `noiseBuffer(ctx)` for white, `noiseBuffer(ctx, "pink")` for pink.
