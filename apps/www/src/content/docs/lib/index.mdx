A library is framework-free: it takes an audio context as a parameter, so it runs in a page, in an `OfflineAudioContext` for an export, and in a test. Its DSP comes from [audio.js](https://audio.js.org) atoms; it holds the glue and the domain. Install each with `npx shadcn@latest add @audio-ui/<name>`.
