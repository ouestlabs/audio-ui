## Usage

An export in one call: it measures the sound's loudness, normalizes it if asked (to its peak, or to -14, -16 or -23 LUFS with the true peak kept under -1 dBTP), encodes it, and says how loud the file came out.

```ts
import { DEFAULT_EXPORT_SETTINGS, exportSound } from "@/lib/audio-export";

const exported = await exportSound(
  channels,
  sampleRate,
  { ...DEFAULT_EXPORT_SETTINGS, normalize: -14 }, // "off", "peak", or a target in LUFS
  (stage, done) => setProgress(stage, done)
);
```

The [Export dialog](/docs/components/base/export-dialog) holds its settings; the measuring is [`loudness`](/docs/lib/loudness) and the encoding [`audio-encode`](/docs/lib/audio-encode).
