## Usage

Undo and redo of any value, as a value: the steps behind it and after it, a gesture recorded as one step, and the last 100 kept.

```ts
import { canUndo, emptyHistory, recordChange, redo, undo } from "@/lib/undo-history";

let history = emptyHistory<Note[]>();
history = recordChange(history, notesBefore); // before an edit
const step = undo(history, notesNow); // { history, present } to go back to, null with nothing to undo
```

`beginChange` and `settleChange` make a drag one step. In React, [`useUndoHistory`](/docs/hooks/use-undo-history) holds it for you; the arrangement's undo is built on it.
