## Usage

The gesture of reordering a row by dragging one of its items: the others slide aside, the item shows dimmed where it would land, a copy follows the pointer, and the view scrolls at its edges, all without a React render while it moves. Call it from `pointerdown` with the press itself: a press that travels under 4 px stays a click, and `Escape` ends the drag.

```ts
import { startSortableDrag } from "@/lib/sortable-drag";

onPointerDown={(event) => {
  if (event.button !== 0) return;
  startSortableDrag({
    axis: "y",
    event: event.nativeEvent,
    from: index,
    ghost: () => ghostRef.current,
    items: rows,
    onEnd: (to, released) => {
      if (released && to !== null) move(index, to);
    },
    onLift: () => setDragging(true),
    scroller: listRef.current,
  });
}}
```

[`useTrackReorder`](/docs/hooks/use-track-reorder) and the [Device chain](/docs/components/base/device-chain) reorder with it.
